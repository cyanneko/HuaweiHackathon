## 少写 BUILD 没有转为少周转

所有流汇总成本变化（候选减 paired100）：

| 分项 | 变化（μs） |
|---|---:|
| BUILD 写 | −409,122.06 |
| PROBE 写 | +8,601,132.71 |
| PROBE 读 | +3,791,958.81 |
| Miss 实际罚值 | +914,357.00 |

BUILD 直接写费减少，后续读写和 Miss 增加。该实验只改变冷启动选择，因而能把这批完整轨迹的变化归于该 gate；它不能辨认“哪个驻留对象/哪次后续决策”承担全部影响，也不证明任何最大对象或增长估计策略普遍无效。

最坏 train600 提供有用反事实：初盘分区 81→2，首 PROBE 前驻留非空分区 431→510，空闲 83,956→21,586,052 B；但后续 Miss 690→812，物理成本增加20.943%。此例 BUILD 写反而增加4,168.69 μs，PROBE 写+36,658.66、读+28,146.11、Miss+106,140。初始保留更多分区/空闲不是当前 paired 后续策略下的充分改进条件。

该例两版 clipped score（截断到0–10的分数）均为0，所以严重退化没有改变其分数；train545 的物理改善也被0分截断隐藏。平均分几乎不变并不能支持尾部无损。另两条>2%退化为 train563（1.040236）与 train637（1.025719）；这些是事后解释，不能拿来另设分流规则或阈值。

## 计时与范围限制

3重复逐流均值再求和的决策时间：旧 paired100 2,826,504.74 μs，新候选2,763,178.25 μs；新候选最长 wall 为2.009秒。候选与复用基线测量窗口不同，公共锁不等于全宿主独占，故不能声称2.24%的决策加速。34条完整同轨迹流也有约+0.000292的平均分差，说明微小分差不能当作稳健性能结论；本次物理均值和尾部已明确未过门槛，停止决定不依赖这个微小计时差。

本轮是旧 Round4 after_probe 机制在 paired100、新训练范围上的单因素复验，非新算法。它补足可信同骨架负结果；不继续扫描最大/最小分区门槛，不叠加增长估计，不改 PROBE。AI 路线负责已有共同状态的集合/续接研究，纯线不重复其 rollout。后续实质任务由主agent结合两线证据另行冻结。
