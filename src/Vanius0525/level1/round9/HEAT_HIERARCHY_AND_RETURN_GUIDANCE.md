# 算子、分区与驱逐重访：下一轮机制依据

记录日期：2026-10-30。用户提出的启发是待验证假设，不把它当成已证明性质。后续两条路线统一100μs代理；旧1μs结果仅保留历史。当前实现入口见CURRENT_WORKING_SOURCES.json。

## 用户意见与采用方式

| 意见 | 可取的机制 | 需要验证或修正的部分 |
| --- | --- | --- |
| Miss总可见，优先利用Miss | 驱逐后的首次Miss有明确对象身份，可直接衡量自己造成的重访风险 | 可见性完整不等于无选择偏差：留在内存的热门对象可能很少Miss。Miss是访问在盘分区，SPILL才是写盘，二者应分项记账。 |
| 用移出后Miss的近期平均时间 | 保存每次SPILL时钟、重访时钟、等待年龄，估计近期重访概率 | 只平均已返回对象会漏掉未返回对象；返回分布的短期风险也不由平均数唯一决定。 |
| 大分区适当少移出 | 显式计算此次写入、未来读入/后续写出的字节成本 | 大分区释放空间也大，一次移出可能避免牺牲多个对象；不能设无条件大对象保护。 |
| 算子偏移叠加分区热度 | 算子层池化稀疏证据，分区层保存偏离与不确定性 | 不能把已是全局概率的分区热度再加一次算子概率，不能从原始Miss数推断算子流量。 |
| periodic足够密则多看Hit | 唯一、已执行且身份已知的next覆盖率高时，更多依赖直接身份信息 | next不等于Hit；它也可能Miss。接口不暴露B，不能按输入B切模型。 |

## 联合热度的含义

令a_o是全局PROBE落在算子o上的概率，b_oj是已经落在o的条件下访问分区j的概率，则p_oj=a_o*b_oj。例如两个算子的流量分别为80%/20%，某分区在各自算子内分别占10%/30%，它们的全局概率是8%/6%；仅看算子内比例会选错。

当前flat估计已经给每个(op,partition)一个全局概率，求和即可得到隐含a_o，但没有单独学习两个层级的先验、变化速度或可信度。只作代数分解没有增量：使用同一组计数和一致先验时，

```
[(c_o+64/K)/(C+64)] * [(c_oj+64/(K*P))/(c_o+64/K)]
    = (c_oj+64/(K*P))/(C+64)
```

这与现行平面估计严格相同。真正可检验的改进包括：算子活跃度与算子内热点采用不同但预先固定的适应速度；分区少样本时向算子内先验收缩；对算子共同行为和分区偏离分别估计不确定性。不能把这些尚未验证的机制宣传为已经提升。

也可以在风险模型的log-rate中用“算子基项＋分区偏移”，保证风险非负并对偏移作收缩；它不是原概率上的任意加分。池化的在盘风险只描述给定暴露/策略下的重访，不能直接当成算子的真实请求份额。

## 驱逐重访的最小可观测账本

以q=hit_count+miss_count作为全局PROBE时钟，保存每个对象的SPILL起点、在盘持续时间、首次重访及结束原因。先仅处理全PROBE阶段，BUILD增长另算，不能假装知道尚未观察到的SWITCH位置。

- 实际Miss：记录精确返回时刻与对象；随后强制LOAD结束这一在盘区间。
- 一直未返回：保留其累计在盘暴露，不能因为没有终点就丢弃。统计上这是右删失，即截至当前只知道等待时间至少有多长。
- next触发预取：它预示下一条确切访问。提前LOAD依赖这条信息，不能当作与访问无关的随机删失，更不能把“没有Miss”解释为冷。单列已知即将重访，并按真实请求序号与后续事件去重。
- 其他提前LOAD、相位改变、统计窗口淘汰：明确各自终止/删失语义，不补造未来返回。
- 没有回调的尾部：在线方法不能读真实输入末尾来补齐匿名Hit或暴露；离线诊断可另标完整真值，不能进入策略。

一个简化的常数风险估计可比较“观察到的返回事件数/累计在盘暴露”，并与只用完成间隔均值的方案对照。它能计入未返回等待，但其概率解释仍要求平稳、终止机制处理正确等条件。非平稳时研究少量时间桶的近期返回风险；先冻结桶和计算预算，不根据新dev或eval扫参数。

对一个候选驱逐集合S，风险应转成行动成本，例如当前写量加上未来H个PROBE内重访概率乘读入与100μs代理，再与原周转近似对照。未来再次写出不是每次必然发生，不能把同一写量重复计入。释放量、当前缺口、next关系与集合终态仍由合法规划器处理，候选数量保持不变。

## 观测融合与AI分工

先分开记录periodic-next、Miss-next、当前Miss、自身驱逐后重访、匿名Hit集合；同一请求各来源共用身份去重。以真实PROBE窗口内“唯一已执行身份/总PROBE”衡量直接观测覆盖，并保留来源和不确定性。高覆盖是更多使用直接信息的依据，不是将Hit优先权写死为一个无法读取的B阈值。

纯算法子agent负责一个低开销的驱逐风险/层级收缩候选及必要消融。AI子agent先检验固定配置是否在真实压力决策上有互补，只有合法特征可区分、动作确实不同且续接成本有空间时，才训练参数选择或局部偏好模型。已有温度oracle改善概率损失却0/23动作变化的负结果要求先检查这个前提。

用户明确允许Python离线训练再导出C++。可在Python中生成特征、按整seed划分、训练小模型，权重/阈值嵌入C++14标准库源码；必须固定特征顺序、归一化、浮点精度与缺失值语义，验证Python/C++输出和最终动作一致。部署不依赖Python、CUDA或模型文件。训练速度与教师轨迹生成速度分开报告；固定统计改进不算AI增益。
