# 驱逐风险静态边界核对（2026-10-30，未运行）

这是设计 V1 的实现约束补充；没有编译、求解器或样本选择。后续执行合同需绑定本文件以及实际参考源码 SHA。

## 区间账的可重建量

两次已记录动作后的合法回调间，设全局 PROBE 时钟由 q0 推进到 q1。上次动作后的驻留集合固定为 R0。每个区间至多有一条提前透露且在区间内执行的 next，记其原始 PROBE 位置 t、对象 j。

- 全局未知请求数 `U=(q1−q0)−1{q0<t≤q1}`，不能按对象单独决定是否扣除。
- 对每个不在 R0 的对象，未知在盘暴露增加 U；它的未知返回计数只可能是区间末当前 Miss，而且只有该 Miss 原始位置不等于 t 才计入。其余对象在这个区间的未知返回为 0。
- 若 j 在上次动作后仍在盘，t 的执行必然产生回调，故它只能是 q1；如果 q1>t，j 必须已被上次动作加载，该已知步骤是 Hit。检查不满足就报观测对齐错误，不能吞掉。
- q1=q0 的重复回调不新增暴露、不执行 live next；同一 `(t,j)` 保留标签而不新增第二份 next。
- 第一回调没有 q0/R0，不把此前 Hit 或该回调当前 Miss 塞入未知风险计数；从真实动作完成后才开始风险区间。它们仍可进入现有 next/当前 Miss 的合法独立日志。
- 初始已在盘对象可从第一次完整 R0 开始贡献未知暴露，但其真实驱逐时间未知。分别报告 `initial_disk` 与本参考策略真正 `SPILL` 过的对象/episode，不能把前者称已知驱逐等待。

区间固定基线 `p0_i`、校准预测 `h0_i` 均在 q0 的新动作前/后同一约定时刻保存，用于未来区间；不得使用 q1 的当前 Miss 更新完参数后再回算本区间准确度。next 已透露但尚未执行可以影响当时合法 p0；由于对应位置统一剔除，恒定 IID 下未知位置与这一条 next 的身份独立。这个 IID 说明不推广为 burst 下的保证。

## 衰减积分，避免稀疏回调改变时钟

设 `a=2^(−1/2048)`，L=q1−q0。旧 D/Z 先乘 `a^L`。每个完整未知位置 u 的新 Z 权重应为 `a^(q1−u) p0_i`，可用有限几何和扣除已知位置 t；不能只把 U 乘以区间末 p_i，也不能把整个长区间都当最后时刻的样本。未知末端 Miss 事件在 q1 权重为 1。L=0 时新增量严格为 0，数值实现用 `expm1` 等稳定公式并独立逐步核对小 L。

原始 U、真实在盘时间、已完成等待分布和 next 已知返回分项不衰减，供账本审核；估计的 D/Z 衰减，两者不能互换。权重只影响近期模型，不会让被删去的已知 next 再次成为未知试验。

## 手工边界预期

| 输入结构 | 必须得到的结果 |
|---|---|
| 每一个 PROBE 执行前均已透露 next（典型 B1），首个可审计区间起 | U=D=Z=0，r=1，h=p；不能凭重复回调增加风险数据。 |
| q0 的 next 是 A；上次动作后 B 在盘；q1=q0+1 请求 A 且 Hit | B 真实在盘时间加 1，但未知风险暴露加 0。 |
| q0 的 next 是 A 并预取；q1=q0+5 才发生 B 的 Miss，B 全区间在盘 | B 真实暴露 5，未知暴露 4，未知返回 1；A 的已知返回单列，不记额外 Miss。 |
| q0 的 next 是 B，B 未能预取并在 q0+1 Miss | 记录真实返回/Miss，U=0、未知事件 0；不能作为“没有返回”或第二份随机 next 证据。 |
| 一个 2 步返回 episode，另一个已在盘 100 步仍未返回 | 两者都保留；已完成均值 2 只作描述，不能据此断言期望等待为 2。 |
| EOF 在已知 next 执行前/执行后但无后续合法回调 | 不使用 EOF 私有尾部信息推进调度器账；pending 与未确认尾部分开报告。离线审计可以说明截断，不能回灌 predictor。 |
| 混合阶段、初始在盘、首回调已为 Miss | 本原型先不建未知的过去；进入全 PROBE 后从第一组完整合法边界开始。 |

## 预测与容量信号的限制

逐对象在盘未知试验的 Bernoulli log loss 可以从合法账重建，但对象之间同一步最多一个返回，因此不能把这些试验视为独立流或由此构造未经证明的标准误。聚合按完整 train 流；数据不足时原样报告，不扩大样本量叙述。

`h_i=1` 对未知未返回给出无限 log loss：应报告这个失败及其计数。若仅为机器汇总使用固定数值截断，必须同时保留未截断非有限计数，不能悄悄把概率触顶问题隐藏。Σh_i 可能不为 1，这是一组风险代理，不能用于 categorical log loss，也不能沿用原 p 的多项协方差声称置信区间。

比较器的风险项仍由原 next p 与旧 n_eff 得到。保留它是控制单因素，不表示它对新 h 更保守。旧当前写量与未来 C 的两处 s/W 分别表示当前动作和可能后续写回；真实未来是否发生取决于轨迹，不能把这个代理视为精确支出预测。
