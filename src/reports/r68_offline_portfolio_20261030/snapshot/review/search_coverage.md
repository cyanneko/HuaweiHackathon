## 后续证据：本倾斜样本已获得接近最优的界

Worker 的 `skewed_refault_chains.json` 回溯发现，raw 4029/3115 的 target 0 前次驱逐分别发生在 raw 3997/3094。当时必须读入另一大分区，两者大小和分别为 80,290,898 / 80,037,331 字节，均超过 M=67,108,864。故上述“保留 target 0”的具体替代在这两个前因位置不可行；不能继续将此处当作已知可改善点。

Root 随后独立编写并运行 `check_capacity_bound.py`，仅扫描原输入、读取已验证解的代价，不调用 solver。输入 SHA256 为 `20d9bb851209473353472bfe0a9a2067282f48059b494d93b678501d375ad59c`。确认所有 INSERT 均在首个 PROBE 前；四个分区大小为 40,957,375 / 39,079,956 / 37,308,233 / 39,333,523 字节，全部超过 M/2。

将 PROBE 序列投影至这四个分区，得到 2,715 次请求和 2,020 次相邻不同分区切换。取每个请求完成、周期调整之前的时刻：目标必须驻留。相邻不同大分区不能同时驻留，所以每个切换区间至少发生一次前者完整 SPILL 与后者完整 LOAD。各区间不重叠，因此这些费用可以相加，不会重复计数。预取可以改变 miss 数及读入时刻，但不能免除这些读写。

官方冻结框架 `round67_offline_quality/framework/offline_dispatch.cpp` 第 504–525 行确认每次有效 SPILL/LOAD 都按完整 data_size 收费且 LOAD 受内存硬限制；第 596–621 行确认 PROBE 完成前目标必须驻留。这里没有假设脏页免费驱逐、允许 bypass 或超容量。

独立求和得到必要写出 79,048,255,738 字节，必要读入 79,048,509,305 字节。W=1000、R=100，故 **L=869,533,348.788** 是允许预取时仍成立的 IO 下界，也是 IO+miss 非负目标的下界。当前官方已验证可行解 **U=872,157,740.986**。

因此对于这一固定输入和物理代价目标，有 `L ≤ OPT ≤ U`，并且：

- `(U-OPT)/OPT ≤ (U-L)/L = 0.3018162%`。
- 从当前解出发，最多还能降低 `(U-L)/U = 0.3009080%` 的成本。

这是一项有条件、可复算的最优性差距证书，适用于本输入，**不包括决策耗时 D，不证明精确最优，也不外推其余样本**。完整整数结果见 `capacity_bound_verified.json`。不把 demand-only 的额外 miss 下界用于允许预取的全部动作域。

结论修正：此前仅根据相对基线下降 0.84% 将此例视为主要弱点并不充分；现在证据表明其物理代价已非常接近最优，后续应优先考察仍有较大可优化空间的其他输入。
