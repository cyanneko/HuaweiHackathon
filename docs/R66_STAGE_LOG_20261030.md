# R66 离线教师与轻量网络：阶段记录

日期：2026-10-30。本文记录一个已验证的训练/部署流程 pilot 和后续教师进展，不是模型晋升报告。当前继续以未封顶得分、完整成本和决策耗时比较方法。

## 最新取舍：先改进离线解

按用户最新要求，下一阶段优先核查官方 Naive 路径覆盖、改进离线可行解质量并调研相关原始论文；暂停新增 NN 训练及参数扫描。本页保留已完成的两个网络及负面结果，不将后续数据生成误写为模型训练。离线教师必须覆盖可比较的真实基线并完整重放，之后再决定是否恢复网络训练。

## 第二批教师已通过外部验证：必须区分官方基线

固定 beam width=8、beam 检查预算 3 秒，外层每例 30 秒上限，对两个按分布/规模预选的 true train 运行：

| 输入 | 当前内部完整回放结果 | 有选择状态 | 相对同状态新池基线的不同选择 |
|---|---|---:|---:|
| beam_06：uniform，KP=32、N=8180 | 自定义三个 incumbent 中最低 G=119407883500，教师 G=94987900900，约降低 20.45% | 109 | 93 |
| exact_05：build_heavy，KP=8、N=782 | 相对最优 incumbent 改善为 0；与 Naive 完整路径相同，优于新池基线 | 4 | 4 |

`G` 是整数缩放后的 IO+miss 物理目标，不是比赛得分或正式 D。第一条约 20.45% **仅相对自定义 fixed-ID largest-first / R65-style / 新池基线**，不能解释成神经网络、在线部署或相对官方 Naive 的收益。目录中的 exact_05 是案例编号，不是最优性证明。

两条新路径后来已通过外部官方框架核验：beam06 为 121 回调/109 标签，exact05 为 211 回调/4 标签，physical/actions/history/pool/order/FP32 features 均一致。

**重要更正：**实测官方 Naive 在 beam06 上的 IO+miss 成本是 **550,505.248**，优于教师的 **949,879.009**。官方 `std::sort` 对等大分区未加 ID tie，与 Python 自定义 fixed-ID largest-first 不是同一策略。原“最佳 incumbent”只能在声明的自定义三策略范围内成立；不得简称“优于最佳基线”。官方 Naive 的完整原动作驱动物理重放已通过，没有修改官方实现。下一轮先检查官方路径在候选池及可表达动作子集的覆盖，不能把池外动作仅注入训练端。

## 标签可表达性诊断

Root 与 Worker 独立计算一致：beam06 的 109 个有选择状态中，103 个所选教师动作有完全相同 16 维 FP32 特征的竞争动作；其中 **87 个**被相同特征且部署 tie 更早的动作压住。对仅按这些特征打分、采用该固定 tie 的确定性共享评分器，最多复现 **22/109** 个教师动作。

这不等于“相同特征的动作未来成本相同”，也不等于不可能改善整体成本。当前模型只复现 1/109，仍有 21 个非强制失败，碰撞也不能解释全部退化。exact04 模型 28/44、exact05 为 4/4。

下一轮先补齐官方基线覆盖证据，再考虑只在每组相同 FP32 特征中扩展部署 tie 胜者的离线分支。必须重新搜索与完整重放，包括重新检查 incumbent，不能给旧路径换动作后沿用原成本。线上 raw pool 和特征无需因此增加复杂度；该限制也不保证一个有限网络能同时拟合所有状态。

## 尚未关闭的风险

- Python 教师的初始三个完整 rollout 和最终验证不受 beam 的 3 秒检查约束，复制完整路径也不适合直接扩大到百万操作；端到端预算必须单独报告和约束。
- 首批新种子验证只有一条有压力，不能据其持平宣称泛化。已安排补充常规随机/倾斜训练数据及长 N 部署验证数据的生成配置，尚未宣称生成或测量完成。
- 教师具有离线信息，在线网络未必能预测随机未来；必须用新轨迹闭环成本验证，而不是只看教师优势或训练损失。
- 无正式 CPU 决策时间、完整新 dev24 结果或总体最优方案结论。
- 当前 adapter 比较时重复计算 best 候选分数，最多 8 候选可能实际调用 14 次前向；不能用理想的 8×136 MAC 作为当前实现总上界。后续缓存 best 分数可省重复推理，但必须保持动作一致性后再测 D；特征/历史/扫描仍另计。

## 教师与部署发布边界

证明最优、受限最优、可行 best-found 与超时必须分别记录动作空间、预算、界及完整 witness；小 KP 或案例名 exact 不等于最优性证明。path_demo 仅是路径示范，不给未运行的候选伪造 Q 值。在线候选池最多 8 个完整方案，16→8→1 共享评分器有 145 参数；当前 adapter 的重复计算可达到 14 次前向，理想 8 次不是当前实现上界。实际发布还需固定源代码、特征、观察历史、权重身份和 CPU 内嵌验证。正式 D 包含候选池、特征、历史与推理全部成本，调试回放时间不能代替正式 D。
