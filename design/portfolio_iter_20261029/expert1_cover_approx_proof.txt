专家 1：固定请求下立即写量的局部 2 近似性质
静态审查日期：2026-10-30

结论与适用范围
----------------
对 design/MySpillScheduler_tree.cpp 的 plan() 进行静态核查：当前构造参数
flags_=351、selected_expert_=1 时，activeRule() 返回 rule8，quota=false，
flags_&1024 为假。因此每个候选的 key=bytes、value=bytes/W，排序是字节数
非递减序。对于一次固定 need、固定排除/保护集合、存在可行解的调用，
在实数计价模型中，返回的 SPILL 总字节数 ALG 满足 ALG <= 2 OPT；其中
OPT 是从同一候选集合中选取总字节数至少达到本次缺口的最小总字节数。
正缺口下，通常的前缀证明还能给出 ALG < 2 OPT。本文采用较保守的 <=。

这是立即写字节（以及固定 W 下立即写时间）的局部保证，不是完整 Score
的近似比，也不是未知未来下的竞争比。不据此宣称后续 miss、读开销、
回调耗时或分类器选择有全局最优性。本文只补充现有实现的数学性质，
不声称“升序前缀加 singleton”这个算法主体具有文献层面的新颖性。

符号和前提
----------
M 为容量，U 为当前驻留字节，d 为 plan 的 need，D=max(0,U+d-M)。
C 为当前驻留、大小正数、且未被 to/tp 与 po/pp 排除的候选集合；
s_i 为候选 i 的整分区字节大小。定义
  OPT = min { sum(i in X) s_i : X subset C, sum(i in X) s_i >= D }。
只讨论可行的固定子问题；若 D=0，空动作最优。空分区不占字节，无须选。
正常引擎状态满足 U<=M，候选个数不超过数组容量，整数字节运算不溢出。
保护 next_op 的候选集合必须视为另一个子问题，不能用未保护集合的 OPT
替代本定义。当前题面 M<=4GB，字节整数可被 double 精确表示，所以
key 的 double 转换不会改变按字节的先后；成本求和的数值问题见文末。

1. forced_cover 提前返回：局部最优
----------------------------------
源码第 225--236 行定义 locked。对于当前调用，locked 包含必须在请求
完成后保留的字节：BUILD 为当前目标旧大小+d，miss 为待加载大小 d；
若额外保护一个当前驻留分区，再计入其大小。令
  F = { i in C : s_i > M-locked }。
任何不落盘 i 的合法结果都至少保留 locked+s_i>M 字节，因此 F 的每个
元素对该固定请求都必须落盘。若 sum(F)>=D，F 本身已覆盖缺口，源码
直接返回 F；任何可行解都包含 F，故 ALG=sum(F)=OPT。
locked>M 时源码不走该捷径；本文仍以固定子问题可行为前提。

2. 小候选集穷举：局部最优
-------------------------
源码第 239--248 行在 n<=10 时枚举全部子集。sums[0]=0，各轮构造含
新元素的全部 mask，用 int64_t 比较达到 D 的最小字节和。因此在可行
前提下 ALG=OPT。相同字节和的 tie 只改变选了哪些分区，不改变本指标。

3. 大候选集：升序前缀与最小 covering singleton
------------------------------------------------
令 s_1<=...<=s_n，k 是首次满足 P_k=sum(j<=k)s_j>=D 的位置。
源代码排序分支先取这个前缀，又比较所有 s_i>=D 的单分区方案，最后
删去仍能保持覆盖的冗余项。因此输出字节不大于 P_k，也不大于最小
covering singleton（若存在）。分两种情况：

(a) s_k<=D。由 k 的最小性，P_(k-1)<D，故
      ALG <= P_k = P_(k-1)+s_k < D+D = 2D <= 2OPT。

(b) s_k>D。所有大小小于 D 的元素都排在 k 前，其总字节数小于 D，
    所以任何覆盖解至少包含一个大小不小于 D 的元素。令其中最小者
    大小为 m；任一可行解成本至少 m，而单独选它可行，故 OPT=m。
    源码对 covering singleton 的比较可得到 ALG<=m，故实际 ALG=OPT。
    如果大小恰为 D 的元素存在，前缀会先覆盖，已属于情形 (a)。

源码第 282--291 行逐项删除的条件是 freed-s_i>=D，保持覆盖不变量，
只减少写量，因此不会削弱上述界。所有比较采用相同 W，实数模型下
value 前缀和与单项 value 都是“字节/W”，没有按字节和按时间混比。

4. 线性捷径保持上述证明
-----------------------
源码第 253--258 行的 flags16 单项捷径，只在升序第一项已经覆盖 D 时
触发。此时最小候选自身可行，任何非空子集不可能写得更少，所以局部
最优；补充扫描 covering singleton 不会变坏。

源码第 261--280 行的两项捷径独立于 flags16。best 和 second 是同一个
less 比较器下的最小两项；仅在第一项未覆盖、两项之和已覆盖时触发，
恰好对应完整排序前缀长度为 2 的情形。两项 value 之和与所有 covering
singleton 的 value 使用同一 bytes/W 单位；单项替换和冗余删除均不增
写量。因此同样满足第 3 节的证明，并非另一个未经证明的截断算法。
同大小分区的 id tie 只改变身份，不改变前缀的字节和或上述结论。

不可外推的边界
--------------
onPartitionMiss() 中可能将当前和下一目标的大小合并后重新调用 plan，
也可能为保护已驻留的 next_op 而用 po/pp 排除它，再按读写收益选择
这个不同子问题的结果。每次 plan 分别适用其固定 D、固定 C 的结论；
最终回调动作不能相对于“只服务当前目标、允许驱逐所有其他分区”的
OPT 宣称同一个 2 倍界。额外 LOAD、下一次访问、历史热度变化及 D
计时也不属于本定理。periodic 的独立 forced() 预载路径不是 rule8 plan。
启用 flags1024 后 key/value 可能附加跨算子 charge；届时字节升序前提
失效，本证明不能直接复用。其他专家的 rule4 等也不在本证明范围内。
