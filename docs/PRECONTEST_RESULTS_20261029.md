# 赛前决策树预热与迭代报告

日期：2026-10-29。本页保留R60/R61历史结果；当前方向是独立非神经网络专家，不继续NN/树训练。正式部署边界：Linux，`g++ -std=c++14 -O2`，纯 CPU，仅提交 `MySpillScheduler` 实现，不修改官方框架。

## 首轮树已经训练，但没有达到推广条件

R61 完整遍历32个训练案例，按输入前、中、后段抽取452个决策状态。每个状态分别执行一次 BF 或 SF 决策，之后按 BF 延续最多32条物理输入，比较 I/O 与 miss 罚分；未来后缀仅用于离线标签，不进入线上特征。拟合约0.72秒，标签生成约24.64秒。

训练比较深度1/2/3和叶节点最小样本8/16，按整个生成家族分组验证。最终选择一层树：目标分区大小除以总内存不超过 `0.0003326743608340621` 时选 BF，否则选 SF。周期回调返回空动作；无需换出的 miss 直接 LOAD。

452个状态里只有17个短窗代价不相等（13个偏好SF、4个偏好BF）。其余435个不能提供专家优劣区分。这些样本也不都是独立事件，不能把452当成充分的泛化证据。

分组验证的宏平均归一化后悔值（越小越好）：固定SF为0.1000，树为0.1667，固定BF为0.2667。树没有超过固定SF，不作为默认方案。

数据为冻结0.4.0、cyanneko全部32个非空eval案例，其他两个成员为空并跳过。各方法与自己的新鲜官方Naive配对，单次重复。表中“倍率”均为方法总成本除以其配对Naive成本，越低越好；这是本地开发成绩，不是官方隐藏集成绩。

新增16个数据文件：8train、8holdout，合法性审计16通过、无错误或跳过。训练部分K=2/P=8/M=64MiB；留出K=3/P=16/M=96MiB，参数与组合不同。包含跨算子混合模式、前后模式反转、交错顺序反转、突发访问、大/小分区循环、阶段重叠、全驻留控制。每例不超过3240条操作。

## 历史树候选计划（当前不执行）

用户提出的定期多专家评分采用可在线实现的版本：每隔64个正式回调，在下一个非周期决策上，让专家对同一真实状态生成候选动作，计算即时I/O等代理值，缓存评分、年龄与回调类型供树参考。不能缓存旧动作供后续执行，不能预读完整未来序列，也不能把代理值称为各专家真正的累计反事实总代价。

此前计划比较三组：R61等价O(1)树、重新采样后的状态树、同一批样本加入稀疏评分的树。两棵重训树使用相同样本/标签/切分，避免把采样变化的收益误归因于评分。仅计算各树实际使用的特征；未被树选中的评分特征不应留下无用在线开销。
