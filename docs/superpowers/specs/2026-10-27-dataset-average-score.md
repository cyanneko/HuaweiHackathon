# 按测试集等权平均的评测规则

按用户在主聊天的最新要求，公共评测默认扫描 `datasets/` 下所有成员目录，使用其中的非空 `eval/`，不再限定三个成员。一个集合的身份是成员目录、该目录的 VERSION 和全部评测文件指纹。

- 省略 `--members` 自动发现全部成员；显式指定成员子集时报告 `partial=true`，即便该列表碰巧覆盖所有已发现成员，也保留显式选择标记。
- 空或缺失集合跳过，不进入分母。非空集合缺版本、输入非法、程序失败或超时，整轮失败且不给有效总分。无集合时同样失败。
- 每案例、每重复先计算官方公式的 single_score，VAL=0 或 BASE=0 时为0；否则 clamp(10*(1-VAL/BASE),0,10)。
- 每个集合内部按重复分别将案例分求和并 cap50，再对重复取均值，得到该集合的本地 Level 1 估分。
- 最终分数是所有参与集合估分的等权算术平均，与各集合案例数无关；原始成本另以原有 aggregate 记录，不作为归一化平均分。
- 报告 schema_version=3，保留逐案例分、逐集每重复分和逐集估分，并提供 normalization.average_score。旧顶层 normalization.level1_estimate 被明确的 average_score 替代。
- 无基线、基线非官方标识或旧协议时归一化为 unavailable。候选/基线同机同输入，报告不认证基线或独立动作合法性。
- 版本指纹、CPU/C++14部署、决策计时、超时、原始输出、重复测量和错误处理保留。

黄金例：A一例得5分、B六例每例9分（单次封顶50），最终(5+50)/2=27.5。不能按所有案例合并封顶，也不能按案例数加权。
