## Hit/Miss信息到底覆盖了什么

24流完整可观察区间合计2,294,066个PROBE，919,585个已执行请求有唯一身份，1,374,481个Hit保持匿名，满足逐区间及全量守恒。首个全PROBE回调前合计192个请求和末回调后95个请求未回填到覆盖分母。

| 身份来源 | 已执行唯一请求数 |
| --- | ---: |
| next去重并集 | 588,635 |
| 其中periodic-next | 95,688 |
| 其中Miss-next | 509,856 |
| 两种next来源重叠 | 16,909 |
| 只在当前Miss暴露、此前无next身份 | 330,950 |

前两种next来源有重叠，不能直接相加；`95,688 + 509,856 − 16,909 = 588,635`，再加Miss-only得到919,585。409,729个提前曝光next后来执行为Hit，已从匿名ΔHit扣除；其中3,461个是在periodic明确预取之后发生的known Hit，没有重复计成新样本。

全身份覆盖率事件加权40.09%、seed等权36.72%；next-only分别25.66%、23.11%。单流全身份覆盖率4.78%–81.90%，periodic-next覆盖率0.0096%–12.50%。这些是已执行身份覆盖，包含策略内生的Miss及预取反馈，不是IID抽样概率、真实B或热度。算子已知身份计数也不能替代真实算子请求量，跨算子匿名Hit没有均摊。

## 结论边界与下一步

本阶段支持继续审查“真实压力状态下强固定估计器之间有没有决策互补”，而非立即训练。下一阶段须等pure风险配置及计算合同冻结，仍固定当前原候选集合，在相同合法状态上比较确定性强配置实际选中动作。若改变p仍不改变动作则停止该学习任务；若存在分歧，才另冻两种续接、真实操作长度对齐、末驻留和读写/Miss分项标签，并检验合法特征能否在完整seed留出上预测稳定收益。分歧出现率须进入全流影响评估，局部条件收益不能替代闭环收益。
