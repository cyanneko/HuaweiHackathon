# 风险尺度归因计划 V1（2026-10-30，待主agent确认执行）

问题：return-risk 总序贯 log loss 改善主要来自 non-event，pooling 未稳定胜过 no-pooling；需要区分整体尺度校准和对象区分信息。原 12 train 的选择、原 paired100 动作、原完整观察账和原两 proposal 保持。此阶段**新增 solver 为 0**，不读取 dev/eval、标签教师或其他训练流，不使用 train600 单例选择常数。

## 唯一新增对照

使用前阶段同一个 D/Z（2048 全局 PROBE 半衰期、未知在盘位置、next 全局排除、区间起点 p、逐步几何权重）构造：

```
g(q)       = (1 + Σ_i D_i(q)) / (1 + Σ_i Z_i(q))
h_scale_i  = min(1, g(q) × p_i)
```

常数 1 沿用前阶段伪返回/伪基线期望，不重新拟合。无风险数据时 g=1。它只作全局尺度校准，保留原 p 的对象排序（截顶只能产生并列）。g 不是算子或全局访问概率，h_scale 不归一化。

预测下一段未知在盘请求时，用段开始时已有 D/Z 和 p，不使用段末事件；在原共同状态比较两个动作时，可以吸收当前已发生 Miss，再用此时的合法 p。没有固定窗口后整批最小化 loss，没有离线挑温度、没有常数网格。h=1 的无限 loss 与前阶段同样记录。

## 只重放已保存证据

绑定前阶段 FINAL_FREEZE/BUILD_FREEZE、每条输入和 observer stderr SHA。使用新命名的离线重放脚本；不修改前阶段审核器。以独立输入/TRACE 为顺序来源，复核原 next、pooling、no-pooling 的每个最终统计与所有 RR_PAIR，再同时计算这个新尺度对照。复算持公共 experiment_lock，逐流释放；只保存小汇总，不覆盖前阶段产物。

## 预定输出与反驳方式

- 按流、算子给 event/non-event/总 log loss 及无限计数；12 流为汇总单位。报告 g 的范围与触顶量。
- 同一原 I/risk/两 proposal 下比较原决定、pooling、no-pooling、global-scale 的决定；记录相对原决定的改变数、各改变集合的交集/互斥、pool/flat 与 scale 的直接差异。不是新轨迹。
- 对各方法真正产生分歧的共同状态，独立重建 history/dynamic 的受害者集合：当前写量、受害者个数、释放量减当前缺口的超额。不得把累加差值当闭环节省，也不把更多/更少受害者自动当优劣。
- 若单一尺度对照已重现风险预测改善和多数动作变化，则分区/算子增量依据弱；停止增加层次模型。若它没重现，仍不能直接归因为区分能力，因为该单对照并未严格匹配每个状态的 Σh 或在盘子集概率质量。先明确剩余混杂，不追加匹配策略/新配置。

本轮不触发闭环或改变下一条数据选择；完成后先报告归因结论，由主agent决定是否还有值得冻结的实际候选。
