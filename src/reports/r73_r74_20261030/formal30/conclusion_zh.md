# R74 正式六例对比结论

原 VanBest、p32、operator、coverage、size 五种冻结版本，在原 R72 六个完整 500 万操作用例上各运行一次；30/30 次有效，零失败或超时，总墙钟约 2 分 20 秒。没有重新编译或追加运行。

本轮 refault 统计有效：operator、coverage 相对当轮原 VanBest 的逐例总成本倍率均值分别为 0.902130、0.902889，即平均降低 9.787%、9.711%，且各六例全部更低。新增决策开销已计入总成本；每完整案例累计 D 分别增加约 0.601 秒、0.665 秒。

p32 对照在本轮基本持平。三个 R74 版本均保留原先的 1/size 固定先验项，没有叠加 p32；因此本轮改善不能归因于罚值先验调整。

coverage 与 operator 互有取舍：coverage 四例更好、两例更差；相对原 VanBest 的逐例倍率均值由 operator 略占优，按历史 Naive 归一化的辅助均分由 coverage 略占优。两者使用不同参照权重，不能混称为同一排名。

size 虽在本轮六例全部胜过原 VanBest，却六例全部不及 coverage，size/coverage 成本倍率均值为 1.011768，并且累计 D 更高。另一个独立保留的机制诊断 synthetic_09 在 penalty=1000 物理成本重算下，size/原 VanBest 为 1.994013；此负结果不混入本轮正式六例，但阻止将 size 默认晋升为通用改进。证据见 negative_diagnostic_evidence.json。
