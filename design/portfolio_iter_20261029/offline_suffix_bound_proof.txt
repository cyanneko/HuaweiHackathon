第20题：离线PROBE后缀耦合下界与min-plus位变换
数学说明，2026-10-30

用途与保证范围

本工具用于离线估计完整Score的乐观下界，不是在线专家，不是可提交的调度器。它允许读取本例真实miss_penalty、B、完整操作序列；这些信息不能进入在线树、网络、专家状态或回调。可以对固定评测输入计算诊断下界，但不使用eval的DP路径、最优动作或价值标签拟合阈值、叶子或模型参数。若将某集合的诊断结果用于后续研发，它也不能继续被称为未见盲测。

以下不等式按非负实数计价成立。普通浮点程序算出的数值不自动构成machine-certified证明；实现必须另行处理舍入、公差与保守下调。

一、依据与切分点

静态依据为保存的design/holistic_20261026/reference_current.cpp和design/neural_selector/teacher.cpp。已确认：
  1. INSERT只增加分区data_size；没有数据删除、压缩或大小缩减。
  2. SWITCH只把算子阶段改为PROBE，不清空数据，不释放内存，不计入周期操作数，也不直接触发周期回调。
  3. 文件结束只打印结果，不要求额外SPILL、LOAD或最终flush。
  4. 全部算子共享固定M；W、R、miss_penalty及B在本例内固定。

要求输入与动作遵守题目约束：每个算子先INSERT、恰好一次SWITCH、随后PROBE，整分区LOAD合法且单分区最终大小不超过M。不能把参考引擎静默忽略非法动作的宽松行为当成许可。

将输入切在最后一个SWITCH之后。prefix包含该SWITCH以及此前所有操作和已发生的回调；suffix是其后全部PROBE。因此prefix中已包含全部INSERT，suffix中所有分区大小固定且所有算子均为PROBE阶段。不同算子提前进入PROBE所发生的读、写、miss仍属于prefix，本下界有意忽略其中一部分正成本。

设所有最终非空分区组成集合U，Q=|U|，分区i大小为s_i>0，A=Σ(i属于U)s_i，即全部INSERT字节。Q是跨所有算子的非空分区数，不是每算子的P。可行驻留集合为

  Ω = { S属于U的子集：s(S)=Σ(i属于S)s_i <= M }。

二、固定大小后缀中两驻留集合的最少I/O

对任意S,T属于Ω，定义

  d(S,T) = Σ(i属于S但不属于T)s_i/W
           + Σ(i属于T但不属于S)s_i/R。

该式是从驻留集合S变为T的最少I/O成本：S\T的分区必须至少SPILL一次，T\S的分区必须至少LOAD一次，其收费给出下界。先SPILL所有S\T，再LOAD所有T\S即可达到它；加载阶段驻留大小单调增加到s(T)<=M，所以全过程可行。

若当前PROBE目标q在S外，且要求miss动作最后LOAD q，只要T包含q，就先SPILL S\T，再LOAD (T\S)\{q}，最后LOAD q。所有中间集合仍是T的子集加上已保留交集，容量不超过M，因此同一个d(S,T)仍可达到。

多次反复SPILL/LOAD不会低于上述下界，因为所有费用非负；本模型每次SPILL都收费，不因已有磁盘副本而免费。

三、suffix反向DP

令V_next[S]表示下一个suffix操作开始时，以S为驻留集合的最小剩余I/O加miss代价；全部决策时间D均被忽略。终值对所有S属于Ω为0：处理完最后操作后没有终止落盘要求。

处理当前PROBE q时，先判断这一步执行完成后是否会触发periodic。定义

  若该步periodic：W[S] = min(T属于Ω) [ d(S,T) + V_next[T] ]；
  否则：         W[S] = V_next[S]。

这里W是“本步PROBE已经服务完、尚待执行可能的periodic”时的剩余成本。随后反推当前PROBE：

  q属于S时：F[S] = W[S]；
  q不属于S时：F[S] = p + min(T属于Ω且q属于T) [ d(S,T) + W[T] ]。

p是真实离线miss_penalty。命中不会调用onPartitionMiss，所以命中时只能由本步实际存在的periodic改变驻留集合。miss先支付p，再通过miss回调到达包含q的T；之后若本步periodic发生，可再次任意改变集合，甚至SPILL刚加载的q，第二段I/O在W中另计。

这个递推对给定初始驻留集合的固定大小suffix，精确求解“I/O+miss”离线最优值。它没有包含D，也没有刻画prefix的完整可达性，因而不能称为整例真实Score的精确最优解。

四、periodic边界必须使用全局计数

令c0为prefix内INSERT和PROBE数量之和。SWITCH不计数。suffix第j个PROBE采用从1开始的j，当且仅当

  (c0+j) % B == 0

时在该PROBE之后发生periodic。不能把suffix周期重新从0开始，也不能用包含SWITCH的行号代替该计数。错误错开周期，可能既多加某些回调又漏掉合法回调，不能保证结果仍是下界。

五、空分区与结束边界

空分区不占容量、不需要读写。在保存的参考引擎中，它们初始驻留，SPILL零大小会被忽略；suffix中无INSERT，故它们一直可视作驻留。

可以将空分区从状态位中移除，但不能从suffix操作序列中删除其PROBE：该操作是hit，仍增加全局操作计数，并可能在操作后触发periodic。对空目标直接应用命中分支F[S]=W[S]。

若Q=0，Ω仅含空集，下界为0，仍不能由此推断真实D也为0。

若suffix为空，F_suffix[S]=0；最后一个SWITCH之后没有额外免费调度或结束flush。若最后一步是PROBE miss，它仍必须在结束前完成LOAD当前目标，不能因为终值为0而省掉这次读与miss。末步可能存在的periodic可以返回空动作，所以不会产生额外必需I/O。

若合法输入没有任何suffix PROBE，工具仍可给prefix写出下界，但不能据此说明prefix中的读/miss已被精确计算。无合法的最后SWITCH、阶段错误或单分区超过M的输入应先拒绝，不应套用此命题。

六、prefix与suffix的耦合下界

令实际执行在切分边界的非空驻留集合为S*。每个在边界不驻留的分区，其全部最终字节此前必已至少写到磁盘一次：若早期SPILL时分区尚未长到最终大小，SPILL写出已有字节，后续盘上INSERT继续写出新增字节；若后期再SPILL，更不会减少累计写出。没有数据删除或结束回收可绕过这一计价。

因此，对这个实际S*，prefix写出字节至少为A-s(S*)，prefix成本至少为(A-s(S*))/W。suffix真实I/O加miss成本又至少为F_suffix[S*]。prefix的读/miss及全部D均非负，故

  真实整例Score >= (A-s(S*))/W + F_suffix[S*]
                >= min(S属于Ω) [ (A-s(S))/W + F_suffix[S] ]。

定义耦合下界

  LB = min(S属于Ω) [ (A-s(S))/W + F_suffix[S] ]。

优化初始S无需满足prefix实际可达性，只会让结果更乐观，不破坏下界。但给定S的prefix代价项不能省略成“初始驻留免费，所有prefix写出也免费”，否则会丢掉这项更强的耦合信息。

因为s(S)<=M且s(S)<=A，对每个S都有(A-s(S))/W>=max(0,A-M)/W，所以

  LB >= max(0,A-M)/W + min(S属于Ω)F_suffix[S]。

这严格说明耦合界不弱于“prefix按总量减M、suffix免费选初始集合”的拆分界。suffix为空时，它退化为

  LB = [ A-max(S属于Ω)s(S) ] / W。

整分区装箱不能总把M恰好填满，因此这个式子还可能强于max(0,A-M)/W。

七、min-plus位变换

枚举所有S,T的直接距离最小化需要O(4^Q)时间。由于d是逐位可分的有向Hamming距离，可以对

  H_out[S] = min(T) [ d(S,T) + H_in[T] ]

使用O(Q*2^Q)的min-plus位变换。首先设置H_in[T]：允许的终点给出其未来值，不可行终点置为正无穷。普通periodic距离变换允许所有T属于Ω；miss距离变换只允许T属于Ω且含q。

对第i位，令r_i=s_i/R、w_i=s_i/W。对每一对仅第i位不同的掩码S0和S1，先保存这一对旧值a=H[S0]、b=H[S1]，再同时更新为

  H_new[S0] = min(a, r_i+b)；
  H_new[S1] = min(w_i+a, b)。

第一式分别表示终点第i位与S0相同，或需要0->1的LOAD；第二式分别表示需要1->0的SPILL，或与S1相同。处理一组位之后，数组已对这些位的所有终点选择取了最小值；逐位归纳，处理全部Q位后便得到完整的min_T表达式。

关键：位变换中的中间掩码是代数消元状态，不是执行顺序。只在初始化允许终点和读取合法起点时使用Ω；不能在每一位更新后把容量不可行的中间掩码重新设为无穷，否则固定的位处理顺序可能先LOAD后SPILL，错误剔除实际上可以先SPILL后LOAD的合法S到T转移，从而抬高结果、破坏下界。

每次开始新的距离变换时，应重新对允许终点施加Ω掩码及必要的q掩码。不要把前一次变换为不可行起点算出的有限代数值，当作新的合法物理终点值。

后缀每步至多需要两次距离变换，故直接实现的复杂度为O(L*Q*2^Q)，工作数组空间O(2^Q)，L为suffix PROBE数。此方法只适合设定阈值内的小Q，不是对题目全部512分区都可执行的精确求解器。

如果Q过大，可以将后缀DP标为未计算，并仅给出仍严格有效的粗界max(0,A-M)/W。不能只采样部分初始S或部分目标T后取最小值并继续声称下界；限制最小化的候选集合可能抬高结果。类似地，启发式装箱得到的驻留和通常不超过真正最大驻留和，代入A-启发式驻留和可能高估必需写出量，不应冒称严格下界。

八、数值实现与解释限制

上述证明采用精确实数加、除与最小值。实现中至少要分开标注：数学命题、计算近似值、保守调整值和与SDK输出的比较公差。普通double/long double、显示时减一个epsilon或局部调用nextafter，都不自动证明整条计算链严格向下。

若要机器可证的下界，需要对参数读取、除法、累计加法、位变换及最终最小值采用完整可证的区间或误差控制。未做这种认证时，应明确写“数值近似的离线下界诊断”，保守下调并在比较时计入SDK累计浮点误差及两位小数输出的舍入影响，不能声称machine-certified。

总字节、集合字节和、周期计数等应保持足够宽的整数；不要为了方便先用浮点相减A-s(S)，更不要把单位字节与微秒混用。

若当前合法策略成本为C、最优完整Score为C*，由C*>=LB可知

  实际可改进幅度 C-C* <= C-LB；
  实际可下降比例 <= 1-LB/C（C>0）。

1-LB/C只是“最多可能下降多少”的乐观上限，不是已证明存在的可实现收益，也不是可训练到的目标。LB接近C时可说明该松弛模型下的余量有限；LB很低或为0时，也可能只是忽略prefix读/miss、全部D、初始可达性等导致界很松。不能据此承诺还有很大真实改进空间。

所有下界产物应保留输入指纹、计价参数、切分位置、周期余数、Q阈值与计算状态；不得把离线最优序列或隐藏参数带回在线提交程序。
