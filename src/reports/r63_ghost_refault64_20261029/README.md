## 开发消融与限制

同一soft底座加/不加ghost的开发对照另见[开发消融](development_ablation.json)。8个已观察组合案例的Ghost/soft逐例成本倍率mean为0.690986934；IO六例好、一例差、一例相同。next_alternation退化到soft的1.162828424倍；全部驻留对照的IO/miss不变，短D波动不能证明Ghost更快。它不是普遍改进，也不是新的盲测证据。

跨算子家族4例的Score倍率mean仍为3.044460，最坏为7.458362。候选D倍率mean3.289162，30/40例D高于配对Naive；历史维护成本和尾部仍需解决。本轮仅保留实验候选，未推广，不把新40例和旧32例汇总直接比较成进步量。未做完整坏例逐动作因果定位。

既有验证包括2次构建、1次边界契约、4条完整状态/物理账本轨迹、36次开发运行和80次正式配对运行。121个子运行不含2次构建。Root独立核对413个证据文件、174个输入、33个源码来源、80份正式输出，并另核对36份开发输出。本次发布只静态核对/重排证据，没有新增构建、solver或训练。
