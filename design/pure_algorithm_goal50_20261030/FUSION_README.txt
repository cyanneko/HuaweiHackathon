融合方式
1. 保留n6的热度/成本规则、已知next保护和近似循环顺序。
2. 纯算法已有后继计数出现支持>=6、保守占比>=40%的上下文时，才启动在线预测。
   暂不启动时禁止使用陈旧预测；漏观测仍作为间断，不补造直接转移。
3. 预测器来自已有DemandPredictor，512x512有界转移计数，每个输入从零开始。
   预测从最后一个合法公开的PROBE之后开始；公开next本身不算预测命中。
   置信度依据先评分再更新的可见连续转移，不能当作所有隐藏PROBE的准确率。
4. 预测仅调整驻留价值：reuse += protection*max(0,1-reuse)。
   要求当前、已知next和预测目标可共存；近似循环已启用时使用原循环规则。
   不增加猜测式LOAD；所有LOAD仍服务当前目标或接口明确公开的next。
5. 候选采用即时预测查询（interval=0）；在线学习与查询开销均计入SDK的D。

选择流程和对照
第一轮8种融合：固定64条new_synthetic拟合；按完整分选择3种不同物理轨迹。
77条独立validation各3次：第一轮u5略低于n6，确认额外开销会吃掉动作收益。
据此增加2种按证据开启预测的候选；重新拟合和验证，按验证分选择当前候选。
同一验证集已参与两轮选择，应视为开发验证；未用50例测试结果选择候选。
