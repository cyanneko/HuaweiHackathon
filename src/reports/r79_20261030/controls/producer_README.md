# R79 independent partition estimator and adaptive operator sharing

Experimental controls, not promoted replacements. Frozen R75 and the official framework remain unchanged. The two R79 policies have identical bytes after substituting the single `R79_ADAPTIVE` definition (0 fixed, 1 adaptive). Both collect the same next statistics; mode changes only the final operator-sharing coefficient.

Partition base uses only its own refault starts/exposure/events and constant prior 64; absent own evidence it returns the independently computed visible heat. Operator raw episodes retain tau128 and are used only for the final blend. An operator with no refault evidence contributes no pooled prior. Dense visible coverage still returns the original visible score. R75 confirmation/censoring/periodic/cycle/next protection and action legality paths are retained.

Each operator stores decaying next mass S, squared partition masses Q, squared sample weights W2, heterogeneity and share. Half-life is 2048 probe ordinals. Per-partition mass is lazily decayed before Q receives `2*old+1`. Only public next PROBE increments this independent sample stream, once per ordinal; current misses only refresh the relevant operator. Group clocks never move backward when a previous peek was at q+1. No full-partition scan is introduced.

For sufficient evidence, n=S²/W2 corrects sampling noise; confidence uses **(S-8)/(S+P)**, so long inactivity returns to the explicit .75 shared prior. H=strength/(1+strength), share=.75/(1+strength). S<=8, n<=8, P<=1, tiny W2 or nonfinite intermediates use H=0/share=.75. This is an IID-inspired cross-sectional proxy from policy-selected next samples, not a guarantee of unbiased request distributions or temporal independence.

Root's pre-panel code review moved score-time sharing refresh into the existing per-release/per-operator cache block, avoiding up to P repeated ESS computations. Current miss/next encounter updates remain immediate. Root also requested explicit H storage; the share formula stayed unchanged. These are static-review changes, not outcome tuning.

Tests: the original R75 fails the fixed-independent-prior expectation; both candidates pass it. A 24,576-step full-vector oracle independently decays all 64 masses and checks lazy S/Q/W2 plus the latest S-based formula at every step. It exercises uniform→single-hot→uniform recovery, duplicate ordinals, no current-miss samples, next-before-miss completion, cross-operator lazy touch, very long inactivity/underflow recovery, P1, pool-independent partition base, dense early return, and prior callback/actual-intent legality fixtures. Test headers expose private members only in test binaries; production binaries have no instrumentation.

Three complete translation units (fixed75, adaptive, and frozen Van paired_penalty100) compile under `g++ -std=c++14 -O2`. Van source SHA is verified against the downloaded commit manifest; its different penalty proxy is intentionally part of that reference and not an isolated R79 feature comparison. Producer records all source/TU/binary identities. No performance matrix or training ran here.
