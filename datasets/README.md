# 三人数据集

本分支集中管理三位成员的数据；`cyanneko` 为已确认成员，`member2`、`member3` 为待重命名占位。

每人目录包含 `train/` 和 `eval/`。`eval/VERSION` 初始值是 `0.1.0`；当前尚未上传真实训练集或评测集，不能视为已完成评测。

修改评测案例后请升级自己的 VERSION，例如从 `0.1.0` 改为 `0.1.1`。评测器还会计算内容指纹，防止只改文件却忘记改版本号。训练数据的变化不会影响评测指纹。

不要把同一操作流放进训练集和评测集；提交前按 [数据规范](../evaluation/DATA_SPEC.md) 检查输入。三人评测集均非空后，使用 [公共评测入口](../evaluation/README.md) 运行。
