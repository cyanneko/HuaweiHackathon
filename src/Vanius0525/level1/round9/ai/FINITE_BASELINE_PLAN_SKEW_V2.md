# 倾斜范围有限计算基线计划v2（执行前冻结）

用户最新指令改变目标分布：不再启动均匀独立请求的性能/学习评测。本计划仅使用Round8概率先导中已冻结的6条V2倾斜train合法轨迹：Zipf、hotspot、lognormal各短/长来源一条。原8流含uniform结果和32seed分层重分析保持旧scope，不能通过删掉uniform制造AI收益。

## 数据与查询边界

- 读取V2 train manifest及已审核的6条合法日志，不读取新正式测试、fresh逐例结果或learning-validation。具体输入/日志SHA在可执行计划JSON中冻结；不glob数据目录。
- 仍检查前缀64/256/1024/4096，共24状态；只能使用前缀之前已发生回调。next最多到prefix+1，预测标签从prefix+2开始4096步。无全PROBE回调的行保留均匀先验，集合指标缺失，不用未来快照补齐。
- 原日志已核查完整TRACE/独立字节账本/匿名Hit身份；本轮不重跑HashJoin引擎。新C++内核只接收去重精确事件和匿名集合事件，不接收真实概率、未来请求或生成器标签。

## 固定统计方法

共同先验为每对象64/n伪计数，无遗忘。批量目标的Dirichlet MAP参数alpha_i=1+64/n，与next-only平滑公式一致。

1. `next_only`：仅来源next的唯一精确身份计数。
2. `incremental`：初始64/n，匿名Hit事件h到达时，以事件前软计数c在驻留A内的比例分配h；然后依次加当前未重复Miss身份、next身份。每次匿名段只分配一次，不回写历史责任值。这是固定统计近似，不声称当前全历史MAP最优。
3. `em1/em4/em16`：在相同合法已见前缀上，从next-only概率暖启动，固定执行1/4/16次全历史匿名集合EM映射。代表少量预算档位，不按成绩增加新步数。
4. `full_mle`：从均匀先验开始，最多1000步，max|Δp|<1e-10，与Round8参考同目标/停止条件。未收敛行全部保留，不按成功筛选或放宽阈值。

所有方法只在相同四个观察时点输出概率；不会给增量法额外真实Hit身份。历史集合的存储和构建必须计入批EM，不能只计矩阵迭代而免除历史成本。

## 测量与检验

- 标准库CPU、C++14/-O2实现估计内核；Python只解析已审核日志、保存评测标签及汇总。
- 共同观测文件读取/解析不算某个估计器独有开销。每方法计入自身事件更新、集合聚合及四次估计的CPU时间；一轮预热后固定3次测量，记录中位数与原值，不挑最快值。
- 报告统计数组/历史集合容量的存储估算及匿名集合数，明确不含分配器元数据等误差；批历史在长流可能继续增长，当前前缀测量不是已实现完整有界窗口调度器。
- 对数损失、概率误差、既有驻留质量误差、相同保留规则的集合变化/价值代理，与充分MLE的概率差距。保留不可辨识等价类和缺失状态，不把软分配当新真实样本。
- C++ full_mle数值与冻结Round8同状态指标核对；增量更新另用Python按相同事件顺序独立复算，防止next先后/重复错误。
