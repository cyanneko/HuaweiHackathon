## 定义与限制

整程G差与suffix G差的整数分子完全相同，因为强制动作之前的真实前缀相同；两个比例的分母不同。原整程包括共同前缀，原suffix从当前动作开始，M入口的已计miss留在前缀。

立即动作IO按同一snapshot中的分区大小、驻留与phase，逐一检查并执行已保存的ordered SPILL/LOAD来计数；不推进输入或运行后续策略。后续残差=整程差−即时IO差，同时列出后续少写、少读、miss罚项的有符号账。

后续残差只是两条已有轨迹的算术分解，不能称为独立因果机制。它包含后续R75决策、驻留演化、读写和miss的共同变化；不能将多个重叠anchor差相加当一条可部署策略收益。

总差为0时即时项和残差可能互相抵消；贡献比例在分母0时保存null。即时项为负而总差为正时，说明当前动作先多花IO，后续残差超过总差；这是有符号分解，不是计算错误。

计算墙时0.018737秒，小于30秒。精确整数G来自原验证账，没有使用stdout两位小数反推。仍仅是8000操作训练样本的同状态Q_R75诊断，不代表AI闭环、总体频率或更大规模性能。
