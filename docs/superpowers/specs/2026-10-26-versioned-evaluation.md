# 三人测试集版本与批量评测

后续当前评分与发现规则见 [2026-10-27 更新](2026-10-27-dataset-average-score.md)：自动发现所有成员，schema 3，逐集合封顶和重复均值后等权平均；下文保留早期接口演进记录。

用户要求创建华为赛题协作仓库，并使评测脚本能够评测测试集，最终成绩附带三个人测试集的版本号，避免成绩与数据版本错配。

实现约定：

- Python 3.10+ 标准库，单个 CLI，接受可执行命令；`{input}` 表示输入文件，也支持标准输入。
- 评测集来自 `datasets/<member>/eval/`，每个非空集合一个 `VERSION` 文件。2026-10-27 用户明确调整为只评测已上传的非空集合，无需三人齐备；缺失/空集合标为 skipped，默认成员仍为 cyanneko/member2/member3，也可显式选择一个或多个成员。
- 报告记录本次实际参与成员的人工版本号、每文件 SHA-256、集合 SHA-256，以及这些集合合并后的评测套件标识；空/缺失成员另列跳过原因。只改变训练数据或被跳过的占位版本不改变评测套件。
- 运行前将测试数据与 VERSION 复制为临时快照。核对输入格式，再对快照逐文件执行候选程序；结果绑定实际执行内容。
- 输出 JSON 明细与终端摘要。默认 official-2026-10-26 五项协议，包括 Total_Decision_Time；只有显式 legacy 使用旧四项。核验计数、非负有限值和含决策时间的代价公式；单人及整体汇总先按案例对重复测量取均值，再求和。
- 每次测量、完整 stdout/stderr、机器、协议、源码/二进制指纹及可得编译器和 flags 均记录。未知身份记 unknown。默认每案例 60 秒，repeats=1。进程墙钟不冒充回调计时。
- 未提供或未标识官方 Naive 基线时归一化 unavailable。显式官方基线在同机同输入串行执行；全部成功后只提供本地 Level 1 公式估计，不冒充比赛总分或独立动作验证。
- 至少一个合法非空集合即可运行；完全无可用集合，或任何被选择的非空集合版本缺失、输入不合法、程序异常、超时或指标异常，退出非零，不提供有效汇总成绩。schema_version=2，报告另列 requested_members/skipped_members，suite_id只绑定参与集合。
- 输出文件不覆盖输入，不覆盖既有成绩。快照执行期间被修改则拒绝成绩。
- 初始化只建 main、datasets、source/cyanneko，预留另两位成员的数据目录；不上传已有研究数据和算法。

采用人工版本号加内容指纹：人工版本号便于交流，指纹负责发现忘记升级版本号的内容变化。仅人工版本号不足以防止错配，单独 Git 提交号会把训练数据和文档变更混入评测版本。
