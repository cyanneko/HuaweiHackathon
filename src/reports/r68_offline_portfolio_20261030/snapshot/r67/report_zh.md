# R67：先改善完整离线解的小样本结果

**四个预选输入均找到优于本轮三个实际基线的完整离线解，最终四条路径已通过官方引擎回放。** 相对各输入的最好已测基线，成本下降 51.06%、46.75%、63.58%、0.84%。本轮停止所有新增 NN 训练；这些是使用完整未来信息的离线结果，不是在线部署收益或全局最优证明。

## 固定输入与真实保底

原输入与 SHA 在 `cases.json` 冻结；配置和源身份在 `config.json`。范围是旧 Vanius uniform 反例 beam_06，以及三个新 seed、每例 7,028 操作/64 分区的 uniform、hotset、skewed 训练输入，后三者实际总 build 字节数约为内存的 2.991、2.981、3.000 倍。不是官方隐藏数据，也没有使用 dev/holdout 求解。

## 六种固定构造的全部成本

`*` 表示该路径当时严格改善已有 verified 保底，因此额外通过了官方完整回放；其余数值来自完成的 Python 物理参考路径，保留但未额外官方重放。相同成本不自动等同于相同动作或相同验证记录。

## 公式与文献边界

令当前 raw 索引为 r，驻留 victim 当前大小为 b_i；t_i 为严格晚于 r 的下一次 PROBE，d_i=t_i-r；S_i(t_i) 为该 PROBE 前所有 INSERT 的精确前缀大小。

- FIF 优先释放较大 d_i。
- size-time 优先释放较大 d_i·b_i。
- cost-aware 优先释放较大 `d_i·b_i / [S_i(t_i)·(1/W+1/R)+penalty]`。

比较使用 Python 任意精度整数交叉乘；代价分母等价写为 `S_i(t_i)·(W+R)+penalty·W·R`，公共 W·R 因子消去。不重复加入 remaining-build 写项。无未来 PROBE 是独立第一优先类别，类内按当前 bytes 降序、ID 升序，不用 infinity 运算。该选择可能增加后续 BUILD 写入；完整真实成本决定是否保留。

[SC17 poster 的官方扩展摘要](https://sc17.supercomputing.org/SC17%20Archive/tech_poster/poster_files/post221s2-file3.pdf)讨论变长对象的离线缓存、未来窗口及按距离估值。它允许 miss 后选择不留对象，本题则有强制整分区 LOAD、SPILL 写入和 BUILD 增长。以上三个评分是本题工程启发，未宣称复现论文的 HCWD 或继承其近似保证。Root 的多篇原文核查及后续路线另见 `docs/20261030_离线调度论文与R67方案.md`。

## 验证、时间与保存

本轮执行了 12 条实际基线，得到 24 条完整参考构造路径；其中 6 条先后严格改善保底并通过额外官方完整回放，最终四个 A 均由其中 verified 路径产生。检查覆盖每个回调的物理状态、下一条公共操作、实际动作、IO 字节账本、hits/misses 和完整 witness 消耗。没有把 24 条全部声称为官方验证。

当前验证器支持的完整动作域是 overflow 仅 SPILL、miss 最后 demand LOAD、periodic 为空；不是对官方所有可选预取/周期行为的穷举。账本 A 保存已验证合法完整解，候选可以在旧 NN 池之外；账本 B 的旧池/相同特征可表达性仍单列。池外动作没有被注入训练候选，本轮也没有导出 Q 或训练标签。
