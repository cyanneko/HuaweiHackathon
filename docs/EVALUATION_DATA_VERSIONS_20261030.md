# 评测数据版本约定

2026-10-30，依据用户在 R86 新版数据评测结束后明确提出的“以旧版为准”。

后续方法选择、改进判断和主要对照报告，固定使用以下完整数据，不抽样：

| 数据集 | 主评测版本 | 完整范围 | 固定 Git tree |
|---|---|---|---|
| dyna_dataset | 1.0.0 | 全部 12 例，每例 500 万操作 | `808ce8b11f57a1a96051f22aa572eceb82b1fba0` |
| final_dataset | 2.1.0 | 全部 eval 72 例 | `41197783dd577dfccf5b007a6ece67cbfb241e4b` |

两树可从固定 datasets 提交 `c65c7b32b06a5764ce9ad4881133a3c6eb33ed17` 获取。冻结原缓存保持不变；公开完整清单、输入指纹及对应程序版本见[统一索引](EVALUATION_INDEX.md)与[R85完整报告](R85_RESULTS_20261030.md)。

每套数据先求逐例平均分，再各占 50%；不把 84 个点等权混合。继续报告未截断 raw、模拟 IO+miss 物理成本、实测决策时间 D、P50/P90 和最差倍率。每个输入的候选与 Naive 必须使用清楚标注的评测批次，历史复用必须明示，不冒称重新测量。Van 的固定源码身份与其他方法一样进入清单。

R86 已经完成的 final_dataset 3.0.0 全72例保留为**补充敏感性实验**。它的72条 PROBE 流均不同于旧版，不能覆盖旧成绩、混入主评测、作为主榜或自动晋升依据。新旧版本的分数变化也不能当作同一算法的改进幅度。

本约定不要求回滚 GitHub 上的数据分支，不删除新数据或已完成实验，不修改冻结的 R84/R85/R86 原始日志和计划；只明确后续工作的主要评测版本。GitHub 索引应区分“当前数据分支最新版本”与“用户指定的主评测版本”。

官方框架、在线可见信息、CPU-only 和 `g++ -std=c++14 -O2` 等要求继续执行最新已核实规则。这里的“旧版”仅指上述评测数据；默认提交方法也不因本次数据版本选择而自动改变。
