# final_dataset · Hash Join 调度整合数据集 1.0.0

500 条训练案例、50 条测试案例。每个 `.txt` 是一条完整工作负载，不是一条 INSERT/PROBE 操作。训练集含 425 条常规案例和 75 条边缘案例（15%）；测试集含 42 条常规案例和 8 条边缘案例（16%）。测试使用仓库规范的 `eval/` 目录，它就是本数据包的 test 集。

本包面向内存受限的分析型数据库 Hash Join：重复热点查询、倾斜键分布、扫描与热点并存、热点迁移、多算子共享内存、BUILD/PROBE 阶段重叠、不同分区大小和算子访问速率。用户未提供真实生产日志，场景比例是工程配方，不代表实测生产流量或官方隐藏分布。

## 边缘案例的定义

普通热点、扫描、分布变化、K/P 端点、随机生成的全驻留案例不因名称或合法端点自动归入边缘。训练中的显式容量/空分区/微小 I/O/对抗构造计入边缘；读写带宽比不小于 1000、累计 BUILD 字节与 M 的比值大于 8 的输入也计入边缘。完整家族名单和全驻留控制路径规则见 `recipe.json`，每个案例的 `is_edge`、`edge_reason` 可追溯。

测试的八个边缘案例各一条：容量恰好容纳、多一字节、接近整块内存的大分区、空分区访问、读写带宽高度不对称、周期回调混叠、长重用距离、显式全驻留对照。边缘仍须符合官方数值范围和输入语义，不包含缺少 SWITCH、越界键值或超容量分区等非法输入。

## 隔离与验证

`manifest.json` 保存全部 550 条输入及元数据 SHA-256、来源、场景、分组与实际统计；`validation.json` 保存独立校验结果。

校验包括严格数值范围、每算子恰好一次 SWITCH、阶段顺序、声明计数、升序算子头、`key % P` 映射及单分区不超过 M。去重分别比较原字节、规范化操作流和带 K/P 头的分区语义流。训练内部、测试内部及训练/测试之间均须无重复；50 条新测试还须与三位成员全部既有 train/eval 输入无重复。原训练被选入本包是有意复用，不能把它与旧训练重复误报为测试泄漏。

训练数据有历史开发暴露。新测试在制作和发布前没有运行求解器、参与拟合、用于调参或按成绩筛选；本次没有基准测试或算法性能结论。公开之后应将它作为固定测试集，若据此调参则属于开发评测，需要另留新测试。输入校验不证明任意算法动作合法或泛化有效。

## 使用和复现

```text
final_dataset/
  train/                 500 份输入和对应元数据
  eval/                  50 份测试输入、对应元数据、VERSION=1.0.0
  recipe.json            预先固定的配额、边缘规则、种子、生成器身份
  manifest.json          文件、来源与实际统计
  validation.json        独立校验报告
  tools/build.py         从固定三方 train 重建 500/50
  tools/generate_eval.py  只生成 50 份新测试
  tools/verify.py         只读验证数据并写报告
```

从仓库根目录执行，Python 3.10+，仅用标准库：

```sh
python final_dataset/tools/verify.py
python final_dataset/tools/build.py
```

重建使用已发布的 `recipe.json`，不换种子、不重选配额。输入若已存在且不同则停止。生成新版本必须另建新目录和冻结配方，更新对应版本和哈希。

本包放在仓库根部，避免默认发现 `datasets/` 成员时把已有来源重复计权。单独运行这 50 条测试：

```sh
python evaluation/evaluate.py --datasets-root . --members final_dataset --repeats 3 --out results/final-001.json --command ./build/solver "{input}"
```

`solver` 替换为已接入正式框架的程序；以上评测命令未在本次数据制作中运行。显式 `--members` 会记录为子集，仅代表本包 50 条测试，不是三位成员全部旧评测的总成绩。报告与性能比较应绑定本包版本、内容指纹和对应程序身份。
