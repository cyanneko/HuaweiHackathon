# Return-risk 均值与风险尺度：静态审查（一页）

2026-10-30。当前全12评测与六份源码保持冻结。本审查不训练、不跑solver，也不依据部分dyna成绩改设计。

令两个原集合之差为 `c_i=sign_i×(s_i/R+s_i/W+100)`，`H=64`，`μ_p=Σp_i c_i`。现行比较为

`I + H μ_h + U_p < 0`，其中 `μ_h=Σh_i c_i`，

`U_p=2H sqrt(max(0,Σp_i c_i²−μ_p²)/(n_eff+1))`。

**保留 U_p 是明确的单因素隔离，不是实现错误；把它称为修正均值的95%置信保证才是错误。** 原 U_p 已是启发式：衰减的 next 样本、策略相关采样量、时间相关与候选选择偏差，均未由 `n_eff=(Σw)²/Σw²` 自动解决。它也不是未来64次实际总费用的过程噪声标准差。

| 情形 | 可严格指出的尺度/不确定性问题 |
|---|---|
| 无截顶的 global，`h=g p` | 给定过去估出的 g 并把它暂视常量，均值等价 g 倍价值。若同步缩放同一估计噪声，标准差应乘 `|g|`；保持 U_p 时，g<1相对更谨慎、g>1相对更激进，**仅指相对该条件化对照**，不是对真实成本保守性的保证。I 没有随 g 缩放。 |
| g 也有估计误差 | 一阶近似含 `g²Var(μ̂)+μ²Var(ĝ)+2gμCov(ĝ,μ̂)`；当前只保留旧 p 风险，后三者的匹配未建立。D/Z 与 p、驱逐时点、未知暴露相互关联，不能假定比值与均值独立。 |
| pooling、逐对象缩放或截顶 | h 不归一。直接将旧式 p 换成 h，`Σh c²−(Σh c)²` 可能为负；截到0不会使它成为合法方差。若**仅作为给定修正系数的价值代理**，令 `a_i=h_i/p_i`（先验保证p_i>0），相应条件二阶矩是 `Σp_i(a_i c_i)²−(Σp_i a_i c_i)²`；仍未计入a的估计误差或选择偏差，不能直接部署成“修正置信界”。 |
| 多受害者与观测量 | 一次真实请求只有一个分区，不能把各对象当独立Bernoulli去掉协方差；D/Z又来自不同在盘暴露集。算子leave-one-out并不让对象独立。保持旧n_eff避免伪造样本数，但不因此保证上界更保守。 |

`Σh`变化还可解释为“有效收益窗口”改变：写成 `H×Σh×E_{h/Σh}[c]` 后，只有分布归一化、却不处理该总质量，就悄悄改变了机制。当前proper log loss（完整事件和非事件概率评分）改善不能证明上述风险项校准，也不能直接推出调度费用改善；沿用 [scale评分研究](RETURN_RISK_SCALE_RESEARCH_V1.md) 的边界。

**最小train-only归因提议（尚未授权执行）：**只取原12训练参考轨迹的全部不同pair，先不造闭环候选；global限定未截顶状态，按合法当时g一次比较冻结的 `I+gHμ_p+U_p` 与 `I+gHμ_p+gU_p`，不扫系数。分别报g<1/g>1、动作改变数、两动作写量/基数及margin；所有截顶状态单列，不能静默丢弃。若完全同动作，停止这条尺度归因；若有差异，只在已有续接标签的**源/输入/状态/两动作逐项完全匹配**时检查分项代价，不借其他流标签。没有匹配标签或差异动作无稳定逐流收益，就停止性能解释，不进入dyna重测、不扩模型；需要新teacher须另冻train协议。该对照只检验固定风险尺度的作用，不覆盖g的不确定性，不能据其通过宣称置信覆盖率。

补查原始研究（仅用于界定缺口，不作为本题已有保证）：

- Howard et al., **Time-uniform, nonparametric, nonasymptotic confidence sequences**, *Annals of Statistics* 49(2), 2021，[arXiv:1810.08240](https://arxiv.org/abs/1810.08240)。通过明确鞅/尾部条件构建持续监测有效的区间；固定2σ乘数不等价于其置信序列。
- Chugg & Ramdas, **Closed-form empirical Bernstein confidence sequences for scalars and matrices**, 2025预印本，[arXiv:2512.21300v1](https://arxiv.org/html/2512.21300v1)。对有界、可时变的条件均值给出方差自适应置信序列。其目标是已观察序列的平均条件均值，不是本题未观察反事实动作的未来64次费用；缺失身份、策略相关暴露和D/Z比值仍需单独论证。未将预印本称为已录用论文。

本审查的可验证错误清单是：把非归一h套类别方差、把U_p叫95%保证、把软/删失分配当新增精确独立样本、或以h评分提升替代费用证据。当前源码没有这些保证性宣称；其均值和风险的有意不匹配是需要单独归因的设计取舍。
