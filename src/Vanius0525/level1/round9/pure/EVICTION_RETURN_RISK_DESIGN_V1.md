# 驱逐重访风险：最小纯算法设计（2026-10-30，待审阅，不是执行计划）

目标是检验：**在相同 next 热度、相同两个可行动作集合上，真实在盘经历能否校准驱逐后的周转风险。** 不把当前 Miss 次数或“只统计已返回对象的平均等待”当全局热度；不同时改 BUILD、保护规则或候选池。参考骨架仅使用 `../candidates/paired_penalty100.cpp`，罚值代理固定 100 μs。文献依据与边界见 [调研记录](EVICTION_RETURN_RISK_RESEARCH_V1.md)。本文件没有授权新 solver。

## 必须保留的两本账

1. **真实周转账。** 全局合法时钟是 `q = hit_count + miss_count`，不是回调次数、墙钟或某算子本地请求数。在 q 的动作中 SPILL 后开始一个 episode；需求 Miss 在 q′ 返回，记等待 q′−q、原写量、实际回读量与 Miss 标志。未返回者持续贡献已观察的在盘暴露；不能只平均完成 episode。初见已在盘者另标“起点未知”，只从首次合法观察开始计暴露，不伪造驱逐时间。非 next 主动 LOAD 是策略相关删失。next 预取单列“已知将在 q+1 需求、提前读入”：在该请求执行获确认后记录已知返回，不能记冷删失，也不能增加 Miss。EOF 不补记未确认的未来事件。
2. **未知请求风险账。** 决策看到 next 后会避免驱逐它；新驱逐对象的下一步常是确定的未返回。故**对所有分区一致排除每个已透露的 next 原始 PROBE 位置**，包括后来成为 Hit 或当前 Miss 的位置；重复回调同一 next 只排除一次。真实账仍保留该步。next 的证据保留在去重 next 基线及“已知返回”日志，不再次充当独立风险样本。B=1 且每步均已透露时，未知暴露与未知返回必须为 0，风险修正回退 next。首回调以前无轨迹的请求不回填。

混合 BUILD/PROBE 暂停该原型、切入全 PROBE 时重置；在合法回调前吸收此前已发生的区间，动作后记录真实驻留。未知位置上，盘上对象不可能隐藏 Hit，故这些位置的“未需求”是可观察的；不能把在内存的匿名 Hit 分配成精确分区样本。对 burst/阶段迁移，历史驱逐条件仍可能与后续相关，以下只是条件风险代理。

## 一个有界、无训练的校准器

令 p_i 是原 paired 的合法 next 概率；过去区间使用**该区间开始时已固定的 p_i**，不回用当前 p 或区间末 Miss。D_i 为未知位置上的返回数；Z_i 为同一对象在盘且位置未知时累计的 p_i 暴露（即基线预计返回数）。两者按全局 PROBE、半衰期 2048 同步衰减；活跃但未返回的 episode 必须更新 Z_i。该半衰期沿用现行热度，不新扫窗口。

对算子 g，用排除目标 i 的同算子统计作有限池化：

```
r_g,-i = (1 + Σ[j∈g,j≠i] D_j) / (1 + Σ[j∈g,j≠i] Z_j)
r_i    = (r_g,-i + D_i) / (1 + Z_i)
h_i    = min(1, p_i × r_i)
```

常数 1 表示预先指定的一个伪返回及一个基线期望返回，不来自成绩调参；这是收缩启发式，**不是已证明的分层后验或置信界**。算子项是相对 next 基线的共同校准，分区项是其偏移；同一分区不重复进入自己的算子先验。冷启动无风险数据时 r=1。r_g 不是该算子的真实访问份额，盘上风险集的组成可能严重偏置。h_i 是单对象条件风险代理，**不强行归一化、也不声称 Σh_i=1 或它就是全局访问分布**；报告 Σh_i 和触顶频率。若需要归一化 p，必须另冻模型，不能悄悄归一化改变本实验。

## 最小候选与归因

先影子：两个原 proposal（history/dynamic）均由原 paired100 产生，逐项完全固定。只把比较式的 `64 Σ sign_i p_i C_i` 替换为 `64 Σ sign_i h_i C_i`，其中 `C_i=s_i/R+s_i/W+100`；当前真实写量、next 已知项、旧风险项与 n_eff 保持。64 沿用原代理，不是已验证的 64 步真实周转模型；旧风险项不是 h 的置信界。大分区已在 C_i 与当前写量中体现，不能再无条件加“大对象保护”。该修改不精确描述首次返回后的再驱逐或终态价值。

唯一机制消融是取消算子池化，即 `r_i=(1+D_i)/(1+Z_i)`；不扩成配置网格。对照原 flat next、同窗口 next-only 和有界匿名 Hit 的定义沿用各自冻结合同，先报告数据来源与历史范围差异，不能把它们的差异都归于风险信号。匿名 Hit 原型只作统计参照，不增加风险 n_eff，也不在本候选里叠加。

## 第一阶段可证伪检查与停止条件

主agent另冻 train 流/种子后，跑 paired100 参考与动作等价 observer：独立重建两本账、已知位置去重、在盘暴露与实际读写；边界覆盖 B1、重复 next、next 预取、长时间未返回、首回调/混合阶段/EOF。先按**更新前预测**统计未知在盘位置的 log loss（真实返回给 −log h，其余给 −log(1−h)，越小越好），避免事后更新造成自证；按流和算子报告，不把 episode 当独立流。全 pressure、两个集合不同、影子选择改变分别给分母；列出当前写差与牺牲对象字节，不把影子选择分歧当收益。固定数组 O(KP)，每回调 O(KP)，不迭代 EM、不分时间桶；实测内存/CPU 后才谈部署。

若未知暴露不足、校准不优于 flat、分歧几乎没有或仅出现在触顶/极少 episode，停止，不改阈值补救。只有合法性、资源与跨流校准均有支持，才申请单候选闭环及整流物理成本验证；局部等待更短或 log loss 更好都不构成整流收益证明。
