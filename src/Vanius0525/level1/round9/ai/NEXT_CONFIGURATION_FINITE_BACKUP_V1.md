# 下一学习问题：风险配置的一次因果承诺（研究设计 V1）

2026-10-30。**当前没有这三个配置的学习增益证据。本文只提出下一训练任务，不授权新 solver、教师、训练或验证。** 当前优先完成已冻结 dyna 全12描述比较；本文不使用其中任何成绩选配置、边界、特征或门槛。原 NEXT_ACTION 的人口门槛失败完整保留，不将其两动作标签换名用于本任务，也不由该失败推断本任务无机会。

## 唯一建议任务及机制差异

在一个合法共同前缀后，模型从已冻结的 `pool / flat / global` 中选一个配置，在预定真实 PROBE 区间内持续使用，随后回到固定续接策略。它学习的是**一段配置承诺的成本**，不是只干预当前 Miss 的两个 SPILL 集合，也不是选择全流最优配置。承诺期间配置会反复改变原两候选之间的门控，继而改变驻留、Miss、预取和曝光；这些变化必须真实执行。

源码依据为 `../pure/RETURN_RISK_DEPLOY_CONTRACT_V1.md` 及三份已冻结100源码：pool `52ae2581…`、flat `4e9a16e0…`、global `7d5cd404…`。三者共享原 paired100 候选池、原 p、风险惩罚项及 D/Z 更新，仅比较中的未来均值不同：pool用同算子其他对象的 D/Z 形成共享先验，flat用对象自己的 D/Z，global仅对全部 p 乘共同强度。h不归一化，原风险项不是h的置信保证。学习delta只能来自**合法前缀信息对这些既有统计偏差的选择能力**，不能来自扩大池、改变100代理或新增高成本EM。

D/Z在同一实际轨迹上可共享，但三条独立闭环运行的D/Z不能拼成一个反事实状态。切换模式不能重置历史、resident、pending next、衰减时钟或检查点；不能让未执行的影子SPILL改变账本。`future()`会推进统计时钟，比较三模式应在一次共同同步的只读快照上计算，不能改变原同步顺序。克隆时须重新绑定 `ReferencePair` 的 `RiskCore*`，不能直接复制仍指向原对象的指针。

## 最小教师提案：先24个独立seed，只检查机会

以下数字是一个可审阅的**单一提案**，尚未执行；未来由root统一合同一次冻结，不搜索边界网格，不据dyna成绩改选。

拟用主2.1训练范围的流为先BUILD后PROBE的倾斜数据，当前设计只检验该范围的配置可学习性；它不是动态漂移适应实验，不能据通过结果宣称dyna泛化。动态配置切换需要另有独立动态train合同，不能取本次已曝光dyna holdout补充训练。

- 只从主锁允许的 train432 取24个独立seed，每族8个；排除已用pilot60及其seed/raw/op/partition近亲，并由root先核实剩余资格。族内固定SHA排序选取；长流覆盖仅用事先固定的输入元数据规则，不能用方法成绩。若不足，报告实际数量，不借dev/eval或dyna holdout补齐。完整seed四折、每折每族2个；后续多状态或派生流仍必须跟随同seed。
- 共同行为为paired100，并只读维护实际动作对应的risk账本。q_base必须是**首次在合法回调中观察到所有算子已PROBE时**的H+M，不是离线知道的最后SWITCH精确时点。提议在 q−q_base 至少4096后的首个periodic回调**返回前**作一次决策；输入仅为该合法回调状态、已维护统计和拟返回动作的确定摘要。q从合法H+M得到；不读B、N、剩余长度、流百分比或生成器阶段标签。首个符合条件periodic不存在则记无决策，不事后替换。
- 当前periodic及其动作属于共同前缀，模型返回的配置从下一真实PROBE开始生效。执行完当前动作后的engine快照仅用于**离线克隆**，不得作为在线模型额外观测或补填特征。提议承诺区间为 `q0 < q <= q0+8192`；在回调入口仅按q选择模式，q越过界时才采用续接，绝不人为插入线上回调。当前端点PROBE的Miss和periodic都执行完才记成本。各分支虽然Miss/回调数不同，原始请求端点完全相同。
- 三承诺配置及不改原paired门控的控制分支，各接 C0=paired100、C1=fixed-global100，记录 `q0+16384` 和 `q0+32768` 两端点。C1是预选的不同续接条件，不是从dyna选出的胜者。最多24次共同collector、24×4×2=192条分支；两端点复用同一长分支，最多6,291,456条分支PROBE。第四臂是现有paired参照，不扩大原SPILL候选池。先固定前两seed的16分支核查，成功复用，不重跑；C0 paired控制分支须与共同collector原TRACE逐字相同。
- 每分支保留读字节、BUILD/PROBE写字节、Miss、SPILL/LOAD、两端驻留集合和D/Z摘要；主标签成本用 `读/R+写/W+100×Miss`，真实隐藏罚值只作离线分项重权敏感性，绝不输入模型。主目标为C0、较短端点；C1和较长端点度量续接及终端敏感性，四项原值都保存，不用逐项min冒充期望。
- 结束前剩余请求不足或发生非全PROBE阶段时按合同记录删失/停用，不补抽、不填零；部署此时采用固定回退。不同端点的有效集合和删失集合分开，未观察长后缀不能宣称全流增益。模型输入中不能包含离线得知的“完整/删失”身份。

这只检验一次有限承诺。通过也不支持每8192请求反复切换，更不能把各窗口最优离线拼接成可部署成绩。若后续研究重复切换，需要新的自身轨迹采集与独立闭环合同。

## 输入、固定参照和启动/停止条件

输入只保留少量无身份的合法统计：已执行唯一身份覆盖及periodic/miss-next/重叠来源比例、next样本有效量、对象/算子D和Z的证据量与不确定性代理、算子间相对强度离散程度及算子内剩余差异、在盘暴露质量、当前占用和对象大小分布、过去真实压力事件中三模式门控分歧率/裕量、受害者数与释放超额的摘要。D/Z没有已证明的置信覆盖，不把证据量叫置信度。q用于因果时钟/衰减；不输入seed、family、N、B、隐罚、未来驻留、未来收益或原始op/partition编号，K/P仅用于合法聚合不作直接识别特征。不把匿名Hit均摊到算子，不把返回者平均等待当全部驱逐风险，不把算子和分区热度重复加分。

固定参照必须包含同前缀/同承诺长度的三个恒定配置，以及全程paired100。比较对象是**最强固定纯配置**；不能只胜弱next-only或旧AI就称学习有效。额外手写门控若使用，必须先固定规则并付相同特征成本，不能观察标签后再把它命名为“强基线”。当前全dyna三固定版本从头使用配置，与共同前缀后的实验不是同一估计量。

机会报告至少给出：全24决策/无决策/删失分母；三个配置实际动作何时首次分歧、完整动作分歧率；每seed的三成本向量、最强固定与逐seed未来最优之间的差；四目标的排序冲突、物理分项及末驻留。全前缀后最优标签可用于**离线监督**，但不允许用未来特征、把预测反用于前缀，或将未来最优直接称模型成绩。共同稳定选择只是一种受限参照，不是所有选择器收益上界。

建议未来合同只设一次实用机会门槛：完整样本上相对最强固定的主目标逐seed等权机会至少0.5%，且至少两配置各在不少于4个独立seed稳定胜出；同一选择在两个续接/两个端点需另报收益与冲突，不能挑有利目标通过。这里0.5%是待root冻结的实验预算门槛，非理论保证或已观测结果。若无真实动作差、一个配置全面支配、收益只由一个seed/少数高删失层撑起，或简单纯门控已吸收全部空间，就停止本候选训练。24seed仅先导，不把192分支当192独立环境，也不以此宣称显著性。失败只否定这次输入/时钟/承诺任务，保持其他配置学习问题开放。

## 如有机会，Python → C++的最小落地

机会成立后，由root审阅并冻结新的低维成本模型阶段，无需据本提案要求用户重复批准：至多12个预定聚合特征，Python拟合三输出线性正则回归预测相对固定参照的成本差；单一正则强度与特征表先冻，不扫树深/margin。所有标准化、固定参照选择和权重拟合只用训练折，按完整seed分层OOF（每seed只由没见过该seed的模型预测）；不确定目标保留四项或降权的规则也须预冻，不能强造确定类别。24seed若不足以稳定拟合，先报告不足，再由root另冻新增独立train规模，不靠同流堆状态补样本。

仅当OOF主目标胜全部固定参照、两续接/两端点不由冲突掩盖、尾部退化可接受，再做真正的一次承诺闭环train验证并包含完整前缀、采样和推理开销；dev/主eval仍需root另行统一授权。实际部署可导出3×(12+1)个double与训练折/最终标准化常数，固定tie规则和回退；标准库C++14足够。现有225权重AI100_EXPORT证明了工程链的可行性，不是新模型的精度或收益证明。新模型仍需逐项float/double语义、17有效数字、权重bitwise、数值边界和完整动作一致性核查。
