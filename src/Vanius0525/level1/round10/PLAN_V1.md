# R80 迁移与两个费用对照

2026-10-30，运行前合同。AI更新/训练/测试暂停，所有性能比较每方法每题只运行一遍。只用已有主60训练流；不重跑72 eval或dyna，不生成新数据集。

## 来源与问题

上游固定提交 `388183be301a09157730d3a4b1e966e7d036bf9e` 的 `src/experiments/r80_van_transfer_20261030/R80_next_hier_fast100.cpp` 原字节保存为本目录 reference。上游报告是 `src/reports/r80_20261030/report_zh.md`，其24例已曝光，不能用于本次拟参。R80_MODE=2在普通PROBE直接用分层next频率生成一个候选，并非当前joint只替换两集合比较的未来均值。按需概率缓存降低计算量；算子内异质性越大，共享越弱。

当前与R80均已结合频率、分区大小和带宽：每对象未来费用代理 `64*p*(s/R+s/W+100)`，按容量排序时除以s。这样能比较不同大小对象；不能把“Miss次数+字节”直接相加。原始Miss次数受驻留策略影响，不能代替p。现有大小因子被除去是单位空间估值，并非忘记读写成本；top4子集又乘回s。研究差异在候选排序及当前写费权重，而不是声称首次纳入大小。

参考依据：现有 `round9/pure/EVICTION_RETURN_RISK_RESEARCH_V1.md` 已核原始LHD(NSDI2018)、LRU-K(SIGMOD1993)、ARC(FAST2003)、hazard缓存上界(TOMPECS2022)和Linux MGLRU；它们支持复用风险/容量联合比较，但不提供本题部分观测、强制整分区LOAD和双向收费下的最优性。这里是本项目单因素可证伪对照，不声称科研新颖性。

## 固定版本，不扫参数

1. `r80`：上游原字节，固定100代理，作为直接迁移参考。
2. `write1`：只将top4子集的当前写费从 `0.25*s/W` 改为 `1.0*s/W`。候选顺序、未来频率/费用、其他路径保持；检查当前写费足额计价是否减少小幅预测收益触发的过量搬运。这仍是有限窗口近似。
3. `value_rank`：只将受害者排序从单位空间价值 `priority` 改成对象总未来价值 `priority*s`；子集损失继续原公式，避免重复乘size变成平方权重。它检验保护大而低频对象是否值得，可能因一次驱逐更多小对象而退化。
4. `mixed_build0`：仅在BUILD/PROBE并存时，将BUILD受害者的子集当前写项从0.25改0。其他阶段与r80相同，仅用一个既有混合阶段小协议例，不进入完整主60。依据是最终会在BUILD落盘者的累计写量与首次写时机无关；不知谁最终会落盘，所以0是偏激的局部对照而非正确性结论，不能免费忽略未来驻留损失。

题面phase属于算子，同一算子各分区不能一部分BUILD一部分PROBE；不同算子允许交错。BUILD盘上INSERT支付追加写费，不产生PROBE Miss罚值，且BUILD不能LOAD。R80对没有PROBE历史的BUILD分区reuse为0，原100项本就不形成当前BUILD Miss惩罚。mixed_build0测试的是机会成本假设，而非修复一个不存在的BUILD Miss计费错误。

## 验证与预算

- prepare绑定原60训练清单/输入/源码/编译器/生成TU/二进制及依赖SHA；先核manifest phase_overlap覆盖。原paired100、joint100、Naive复用已有冻结二进制。
- 三个主候选各运行一次已有5条小协议并逐动作/整数字节审核；mixed_build0只运行一次原mixed协议，与同轮r80审核比较。16次小协议审核不用于性能计分。没有新协议组，也不重跑同一方法/输入。
- 完整60 train × (r80/write1/value_rank/paired100/risk_pool100/naive) = 360次未插桩运行，各一遍，逐case确定性打乱顺序。检查身份、退出、有限输出、Hit+Miss、费用公式及60秒wall；不另跑这60的插桩副本。明确小协议审计不等于全部60轨迹重放。
- 同一case按同轮Naive计算含决策分数，同时报告物理成本比、Miss、均值/最坏退化和决策时间。physical=IO+真实罚值×Miss；所有在线代理100。不把不同策略决策时间差全归因于统计组件。
- 主60既有开发曝光，结果是训练诊断。候选进入后续审阅须：全通过上述核查、物理/paired均比≤0.995、最坏≤1.02、含决策均分≥paired；两个新对照还须对r80物理均比≤0.995、最坏≤1.02、均分≥r80。没有候选满足就保留负结果，不扩网格或改变门槛。满足仅允许后续制定验证，不立即晋升或访问dev/eval。
- 失败保留原输出/执行记录并停止，不能静默重试。持现有experiment_lock串行；共享锁不保证整宿主独占。结束后独立复核、更新HANDOFF、精确发布本阶段文件。
