# 有界匿名Hit统计原型契约 v1（2026-10-30，运行前冻结）

范围：无学习的纯统计基准；只做合法事件、影子数值及资源核查，不改paired动作、不训练温度/校准模型、不查询新主测试。上一有限next与core影子诊断不重跑。当前参考仍为冻结Round8 paired（SHA `8c040b8778ab9afa60df432d393466b174c3faf2a691fef2c8c84fab000b6287`）。实现与结果另行版本化绑定。

## 唯一固定预算及来源

| 项 | 固定值 | 选择依据与限制 |
|---|---:|---|
| 完整已发生回调区间 | 最近256个 | 固定数组存储，在512对象上将新增估计状态控制到64KiB以内；不是选成绩得到的窗口，也不是256请求 |
| 尚未执行的已知next | 额外1个live精确因子 | next合法提前曝光，但必须与已发生区间分开，执行后搬移，不能重复计数或因旧窗口淘汰而丢失 |
| Dirichlet伪计数总量 | 64，每对象64/n | 与既有强统计基线/paired先验一致；不调先验 |
| EM映射步数 | 固定16 | AI冻结有限基线中已接近充分MLE；不新增步数网格。仍不等于收敛保证 |
| 刷新 | 首次有效观测；以后真实PROBE序号较上次拟合至少增加1024且有新信息 | 明确限制最坏拟合次数到每epoch至多1+floor(N/1024)，1024来自既有诊断时点/运算预算，不按收益选取 |
| 无有效匿名集合 | 同窗口精确后验闭式解 | 不做无用EM；全对象集合的Hit似然为常数，也从EM目标中精确消去 |

256个完整区间的实际PROBE跨度随Miss/periodic而变，必须记录均值、最大值及每个数值检查点跨度；不能叫固定PROBE滑窗，也不宣称匹配paired的2048半衰期。合法B上限10000给出至多约256万PROBE跨度的粗上界；长Hit段不会被按未来身份切开或按比例猜测。固定16×256×512两遍集合扫描的保守上界为每次拟合4,194,304次成员访问，另有O(16n)归一化；允许同mask确定性合并与常数项消去，但不增加预算。必须测实际CPU，不把这个上界称低开销。

## 回调前吸收，动作后提交驻留

每次callback先调用`before(state,tag,current_target)`，只读取合法SystemState；随后运行原paired生成原动作；再调用`after(state,actions)`记录这些动作**将产生**的驻留集合，最后原样返回给官方引擎。引擎动作合法性由独立账本审核。统计拟合发生在原动作生成前，不能用本次将选动作或以后Hit更新本次概率。

只在全部算子为PROBE的epoch启用。混合BUILD/PROBE时丢弃未闭合区间并重置本统计epoch，paired自身仍保持原行为。进入全PROBE的第一回调没有合法前置驻留区间，不补记此前匿名Hit；可记录当前Miss精确身份和合法next。尾部没有新回调就没有新观测，不在析构时用输入文件补齐。

两个回调之间驻留集合必须等于上次`after`结果。令q=Hit+Miss，ΔMiss在Miss回调必须为1，否则为0；计数不得倒退。上次live next若已经执行，其精确身份搬入新完成区间：若为Hit，从ΔHit扣1；若为本次Miss，与当前目标去重。其余ΔHit作为匿名事件`h log(sum_A p)`，A是上次动作后的驻留集合。当前Miss若并非已知next，再增加一个精确身份因子。每区间至多两个精确身份。

新的next单独保留为live因子`log p_next`。同一q的Miss后periodic共享同一个next，不新建有重复请求的区间、不再增加精确因子。预取可能使已知next变Hit，仍须从匿名Hit中扣除；动作后驻留记录承担这个判断。精确身份按请求序号去重，不按对象ID去重，所以连续重复同一对象的不同请求都应保留。

**窗口淘汰必须以完整区间为单位。** live因子只在真正执行后搬入其所属新完成区间；这样即使前一回调区间被淘汰，已知Hit也不会既从匿名数扣除、又失去精确身份。淘汰时同步扣除该区间的精确计数与匿名集合，禁止只裁匿名Hit留下由Miss选择的精确事件。

## 有界目标、初始化与风险

目标是保留的完整区间、live next与先验的集合似然MAP；不是全历史MLE，也不是完整身份观测。每次从**同一有界历史中next来源精确身份**的平滑后验初始化，执行16次确定性EM。live next属于next来源；已知next执行后保留来源标记；未提前曝光的当前Miss不属于next来源。没有隐含真实概率、family、seed、N、B或罚值输入。

软分配的匿名Hit不是真实身份样本，不写入原paired的sample_count、sample_squares或n_eff。当前阶段新概率不参与任何规划，旧risk/动作保持逐字等价。未来若单独批准部署，可在同一旧候选集合上用新概率评估均值、用旧next概率与旧n_eff计算旧风险代理，作为明确的设计选择；这不是联合估计的置信界，也不保证更保守。当前不替换这个评分或生成新候选。

尤其要区分“相同规划器代码”与“相同动作池”：替换dynamic规划器内部probability会改变其候选身份。本阶段不作这种替换；未来动作池/估值的影响必须分开验证。重复相同集合的对象若缺少精确/分离观测，只能识别其概率和，EM不会创造可辨识性。

## 冻结核查范围

1. 自含边界序列：第一回调、重复next、Miss紧接periodic、预取后的已知Hit、同对象重复请求、长匿名Hit、B=1无匿名信息、全对象集合常数项、混合阶段重置、256区间淘汰跨live搬移、末尾无回调。检查精确/匿名账本与有限概率和、数值非负、固定存储上界。
2. 原6条pure skew训练流的完整paired轨迹（与core诊断相同seed，不依据结果重选）。官方基线/影子TRACE逐字一致，完整动作与字节审计；只重跑本新观察机制，不重复上一诊断。所有solver/重计算持公共锁。
3. 数值检查点是各流首个q≥64/256/1024/4096的合法全PROBE回调，报告实际q及上次拟合q。离线比较同一合法观测前缀下：保存全历史的16步参考、同有界目标的16步独立重建、部署刷新频率产生的当前缓存概率。它们目标/新鲜度不同，不把概率差等同预测或调度收益。不读取隐藏真实热度做在线估计。
4. 记录估计器实际对象大小/数组容量、拟合次数/区间数/匿名成员扫描量、区间实际覆盖PROBE跨度、资源测量；时间必须包括更新与拟合，区分墙钟与进程CPU。诊断I/O及官方paired时间单列，不把带日志的整个wrapper时间冒充可部署内核时间。原型失败按冻结版本记录，不在partial结果后改窗口或刷新频率。

通过这些核查也不代表可晋升；后续完整候选、闭环成本和AI增量仍需独立计划。无有效匿名信息时快路径必须正确，统计不可辨识/快速迁移/低回调频率的局限保留。
