# 独立统计内核资源核查（运行前冻结）

用户已要求后续调度器统一100微秒代理。此前22次旧paired影子检查已正常结束，保留为旧骨架的历史观察；此补充**完全不调用调度器、没有罚值参数，也没有闭环成本选择**，不能冒充100代理的候选证据。

固定统计内核为已冻结`bounded_hit_v1.hpp`，不改256区间/16EM/1024刷新等参数。仅构造两个合法回调资源序列：512对象、每对象256KiB、256对象驻留等于64MiB；请求15/16落在固定resident对象0，剩余1/16轮转257个冷对象。冷Miss先完整spill原buffer，再load当前目标，保留255个core；periodic不执行动作。该确定性倾斜序列用于边界/资源压力，不能作随机泛化或策略收益数据。

回调周期仅固定B=1（零匿名Hit快路径）和B=17（有匿名集合和轮转驻留）两种语义，不按成绩挑B。每次4,999,480 PROBE，加上合法512 INSERT及8 SWITCH前缀，恰对应题面最大5,000,000操作；内核仅运行全PROBE后缀，不计入构造前缀费用。next来自这个测试请求序列，恰为下一真实请求；不给估计器B或未来长度。

每case先固定2048 PROBE预热，随后3重复按repeat轮换B=1/B=17，记录全部值与中位数，不挑最快值。一次进程CPU/墙钟包住完整生成/事件更新/拟合循环，避免逐callback计时的量化开销；包含测试序列生成和驻留位更新，因此不是纯EM单步时间。所有编译/运行公共锁。内核只用固定数组，记录sizeof、最大区间数、实际跨度、拟合次数和成员访问量；这不是真实进程RSS或全求解器内存。
